---
title: Animations
description: useCharacterAnimations loads the shared KayKit animation packs for a rig size, merges embedded clips, and exposes play/stop with fade, timeScale and one-shot options.
---

`useCharacterAnimations` (from `@artificer-forge/engine/runtime`) loads the eight shared animation packs for a rig size, builds one `AnimationAction` per clip on the given rig, and gives you `play` / `stop` with crossfade.

```ts
import { AnimationName, useCharacterAnimations } from '@artificer-forge/engine/runtime'

const { play, stop, currentAnimName, actions } = useCharacterAnimations(rig, 'Medium')

play(AnimationName.RUNNING_A)                              // crossfade 0.3 s, loop
play(AnimationName.WALKING_A, 0.3, 1.5)                    // fade, then timeScale
play(AnimationName.DEATH_A_POSE, { fadeTime: 0.3, once: true })
stop()
```

## Signature

```ts
export function useCharacterAnimations(
  rig: MaybeRef<Object3D | undefined>,
  rigSize: RigSize = 'Medium',
  embeddedAnimations?: MaybeRef<AnimationClip[] | undefined>,
)

export type RigSize = 'Medium' | 'Large' | 'Small'

export interface PlayOptions {
  fadeTime?: number   // default 0.3
  timeScale?: number  // default 1
  once?: boolean      // default false
}
```

| Param | Type | Default | Purpose |
|-------|------|---------|---------|
| `rig` | `MaybeRef<Object3D \| undefined>` | required | Armature root. Actions are only created once it is set |
| `rigSize` | `RigSize` | `'Medium'` | Which pack folder to load. Single-GLB characters derive it from `entity.rig`; modular ones from the body part's rig (`small` → `'Small'`) |
| `embeddedAnimations` | `MaybeRef<AnimationClip[]>` | `undefined` | Clips from the character GLB itself, appended after the packs |

### Returns

| Property | Type | Purpose |
|----------|------|---------|
| `actions` | `Readonly<Record<string, AnimationAction \| null>>` | One action per clip name, from cientos `useAnimations` |
| `currentAction` | `Readonly<ShallowRef<AnimationAction \| null>>` | The action last started by `play` |
| `currentAnimName` | `DeepReadonly<Ref<AnimationNameType>>` | Starts as `Idle_A` |
| `play(name, fadeTimeOrOpts?, timeScale?)` | see below | Start a clip |
| `stop(fadeTime = 0.3)` | `(number) => void` | Fade the current action out and forget it |

## Animation packs

```ts
const ANIM_PACKS = ['MovementBasic', 'MovementAdvanced', 'General', 'CombatMelee',
                    'CombatRanged', 'Simulation', 'Tools', 'Special'] as const

const animBase = `/models/animations/Rig_${rigSize}/Rig_${rigSize}_`
// -> /models/animations/Rig_Medium/Rig_Medium_CombatMelee.glb
```

Each pack is one `useGLTF` call. The composable concatenates `state.animations` of all eight plus `embeddedAnimations` into `rawAnimations`, and only hands them to `useAnimations` once `rig` is truthy. The files ship in `@artificer-forge/assets` under `files/models/animations/Rig_{Medium,Large,Small}/`.

::note
Packs load one by one, so `actions` grows in steps. A `play(name)` for a clip whose pack has not arrived is a no-op (`if (!newAction) return`). The composable re-issues the current animation when actions are rebuilt (see below), but it does not queue a missed request.
::

## `play`

```ts
function play(name: AnimationNameType, fadeTimeOrOpts: number | PlayOptions = 0.3, timeScale = 1)
```

Two call styles. A number is the fade time (with the optional third `timeScale`); an object is `PlayOptions`.

What it does, in order:

1. Same action already playing: only `setEffectiveTimeScale(timeScale)`, then return. This is how the controller changes walk speed without restarting the clip.
2. `reset()` (clears a finished `LoopOnce` state), `setEffectiveTimeScale`, `setEffectiveWeight(1)`.
3. `once`: `setLoop(LoopOnce, 1)` and `clampWhenFinished = true`, so the last frame holds (death poses). Otherwise `clampWhenFinished = false`.
4. `play()` the new action, then `fadeOut(fadeTime)` the previous one.

The new action is **not** faded in; it starts at full weight while the old one fades out. Pass `0` for a hard cut:

```ts
play(AnimationName.HIT_A, 0)
```

### `timeScale` contract

`timeScale` is a playback multiplier relative to the authored clip speed. The pointer controller passes `speed / baseAnimSpeed` (default `3 / 2 = 1.5`) so the feet match ground speed ([Controller](/characters/controller)). Callers that pass an object without `timeScale` get `1`.

## Auto idle and pack reloads

```ts
watch(() => Object.keys(actions).length, (len) => {
  if (len === 0) return
  if (currentAction.value && actions[currentAnimName.value] && actions[currentAnimName.value] !== currentAction.value) {
    // actions were recreated (a new pack landed): the current action is orphaned, restore it
    const wasOnce = currentAction.value.loop === LoopOnce
    currentAction.value = null
    play(currentAnimName.value, { fadeTime: 0, once: wasOnce })
  }
  else if (!currentAction.value) {
    play(AnimationName.IDLE_A, 0)
  }
}, { immediate: true })
```

cientos rebuilds every action when the clip list changes. Without the restore step a character would snap to T-pose each time a pack finished loading. `Idle_A` plays as soon as the first pack with it (`General`) is ready.

## Who calls `play`

| Caller | Clip |
|--------|------|
| `usePointerController` | `Walking_A` on `moveTo` (with timeScale), `Idle_A` on arrival |
| `Character.vue` | `Death_A_Pose` `{ once: true }` when `hp <= 0` or `dead` |
| `useActorBehavior` | `ai.idleAnimation` or `Idle_A` |
| `useStatusEffectAnimations` | periodic `Hit_A` flinch for `flinch: true` effects |
| Ability system | `abilities/*.yaml` `animations.execute` (e.g. `Melee_1H_Attack_Chop`) |
| `CharacterRef.meleeAttack()` | `Melee_1H_Attack_Chop` |
