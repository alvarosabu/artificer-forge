---
title: Encumbered
description: Over-capacity inventory status applied by the game store, not in the id list and without a YAML definition
---

`encumbered` is applied and removed by the inventory code when carried weight reaches capacity. It is the odd one out: it is **not** in `STATUS_EFFECT_IDS`, and there is **no** `encumbered.yaml`.

## Source

`useGameStore.syncEncumbrance` (`runtime/stores/game.ts`) runs after every `moveItem` for the source and target containers:

```ts
function syncEncumbrance(characterId: string | null | undefined) {
  if (!characterId) return
  const character = entities.value.get(characterId)
  if (!character || character.type !== 'character') return
  const ratio = encumbranceOf(characterId)
  const hasEffect = character.statusEffects?.some(e => e.id === 'encumbered') ?? false
  if (ratio >= 1 && !hasEffect) {
    addStatusEffect(characterId, 'encumbered')
  }
  else if (ratio < 1 && hasEffect) {
    removeStatusEffect(characterId, 'encumbered')
  }
}
```

`encumbranceOf` is `encumbrance(weightOf(id), capacityOf(id))` from `core/inventory.ts`. See [Stackables and weight](/inventory/stackables-and-weight).

## What the code does with it

| Layer | Behavior |
|-------|----------|
| HUD | `StatusEffectBadge` renders, but `store.get('encumbered')` is `undefined`, so the circle has no background, no icon, and no tooltip text |
| Floating text | `useStatusEffectTexts` falls back to the raw id: white "encumbered" |
| Command palette | **Remove Status Effect** skips it with a `console.warn` (`Unknown status effect id`); **Add** never offers it |
| Overlay / particles / animation | None |
| Gameplay | None beyond the badge. Movement is not slowed. |

::caution
Two fixes are needed before this status renders like the others: add `'encumbered'` to `STATUS_EFFECT_IDS` in `core/statusEffects.ts` (the `addStatusEffect(characterId, 'encumbered')` call does not match the `StatusEffectId` union today), and add `content/status-effects/encumbered.yaml`. The legacy `STATUS_DEFINITIONS` table in `useStatusEffects.ts` already carries values you can copy: `i-lucide-weight`, `text-stone-300`, `bg-stone-800`.
::
