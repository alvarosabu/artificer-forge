---
title: Shocked
description: Crowd control status inflicted by electrified water or blood, badge only
---

A magical crowd-control status. It is badge-only: no overlay, no particles, no animation, and no gameplay code reads it.

## Definition

`apps/playground/content/status-effects/shocked.yaml`:

```yaml
statusEffectId: shocked
label: Shocked
type: cc
armorGate: magical
color: text-cyan-400
bgColor: bg-cyan-950
icon: i-lucide-zap
flinch: false
```

::status-effect-badge{effect-id="shocked"}
::

::note
`shocked` and `hasted` both use `i-lucide-zap`. The colors differ (cyan on near-black vs blue on dark blue).
::

## Sources

- Standing in a `water` or `blood` cell with `electrified > 0`. `statusForCell` checks the charge before the plain liquid check, so an electrified pool inflicts `shocked` instead of `wet`. A lightning strike holds the charge at 1 for 3 seconds, then it decays at `0.5/s`. See [Surface variants](/surfaces/variants).
- The command palette.

Like every surface status except `warm`, it is not removed when the character steps out. Remove it with the palette or `gameStore.removeStatusEffect(id, 'shocked')`.

## What the code does with it

| Layer | Behavior |
|-------|----------|
| HUD | Badge in `Nameplate` and `CharacterPanel`; floating "Shocked" label from `useStatusEffectTexts` |
| Overlay | None (`StatusOverlayEffectId` is `poisoned \| burning \| frozen`) |
| Particles | None |
| Animation | None (`flinch: false`) |
| Gameplay | None. The `cc` type and `magical` armor gate are stored but not read. |
