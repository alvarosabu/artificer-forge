---
title: Slowed
description: Debuff inflicted by oil surfaces, badge only, no movement speed code
---

A debuff contracted from oil. It is badge-only. Like `hasted`, nothing reads it to change movement speed.

## Definition

`apps/playground/content/status-effects/slowed.yaml`:

```yaml
statusEffectId: slowed
label: Slowed
type: debuff
armorGate: none
color: text-amber-400
bgColor: bg-amber-900
icon: i-lucide-snail
flinch: false
```

::status-effect-badge{effect-id="slowed"}
::

## Sources

- Standing in an `oil` cell (`statusForCell`). Oil pools decay after 30 s, but the status stays on the character.
- The command palette.

## What the code does with it

| Layer | Behavior |
|-------|----------|
| HUD | Badge in `Nameplate` and `CharacterPanel`; floating "Slowed" label from `useStatusEffectTexts` |
| Overlay | None |
| Particles | None |
| Animation | None (`flinch: false`) |
| Gameplay | None. `useCharacterController` uses a fixed `speed: 3` and has no store access. |
