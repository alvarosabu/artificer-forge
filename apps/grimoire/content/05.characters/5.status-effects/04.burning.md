A damage-over-time effect with the most complete visual treatment: a multi-pass FBM flame shader, rising ember particles, and the flinch loop.

## Definition

`apps/playground/content/status-effects/burning.yaml`:

```yaml
statusEffectId: burning
label: Burning
type: dot
armorGate: magical
color: text-orange-400
bgColor: bg-orange-900
icon: i-lucide-flame
flinch: true
```

::

## Sources

- Standing in a `fire` surface cell. The effect stays after the character leaves the fire.
- The command palette.

While `burning` is present the surface system never adds `warm`, and `burning` has top overlay priority (`burning > poisoned > frozen`).

## Shader Overlay

The burning overlay uses two-pass FBM (fractional Brownian motion) noise for realistic flame rendering:

:::div{class="grid grid-cols-2 gap-6 items-start"}

![Burning Overlay](/status/burning.gif)


| Parameter | Value |
|-----------|-------|
| Noise type | Two-pass FBM (`mx_fractal_noise_float`) |
| Color ramp | Red → Orange → Yellow (3-stop gradient) |
| Flow direction | Upward |
| Flow speed | `1.2` |
| Scale | `4.0` |
| Sharpness | `2.5` |
| Pulse speed | `4.0` |
| Intensity | `1.2` (brightest overlay) |

:::

### Flame Composition

- **Pass 1**: Low-frequency FBM warp (2 octaves at `scale * 0.35`) displaces X/Z by up to `0.3` so flames sway laterally
- **Pass 2**: High-frequency FBM (4 octaves) at `scale` with the warp applied shapes the flame body
- **Flicker**: Two overlapping sine waves (`pulseSpeed` and `pulseSpeed * 2.7`) produce an organic pulsing beat
- **Height mask**: `smoothstep(0, 0.7, positionLocal.y)`: flames fade near the feet and reach full intensity from the knees up

### How It Works

`buildBurningEmissiveNode(cfg)` in `@artificer-forge/vfx` generates the flame pattern in TSL. The first noise pass warps the sample position laterally, the second adds detail. The raw FBM (about `-1..1`) is remapped to `0..1`, raised to `sharpness`, then color-ramped `#bb1100 → #ff5500 → #ffee44` (the yellow stop uses `shaped^2.5`, so only the hottest tips turn yellow). The result is multiplied by both flicker sines, the intensity, and the height mask before `useStatusEffectOverlay` assigns it to `emissiveNode`.

## Ember Particles

`useStatusEffectParticles` adds `createEmberSystem().points` (from `@artificer-forge/vfx`) to the rig when `burning` appears and removes and disposes it when the effect goes away. It is a `THREE.Points` with `PointsMaterial`, `vertexColors`, `AdditiveBlending`, `depthWrite: false`, size `0.05`, `frustumCulled = false`.

| Constant | Value |
|----------|-------|
| `EMBER_COUNT` | 60 |
| `CHAR_HEIGHT` | 2.2 units (initial height stagger) |
| `MAX_RADIUS` | 0.55 units from character axis |
| `RESET_Y` | `CHAR_HEIGHT + 0.4 = 2.6` |

### Particle Behavior

Each ember has an `EmberMeta` record:

| Property | Range | Description |
|----------|-------|-------------|
| `angle` | 0–2π | Cylindrical angle |
| `radius` | 0.12–0.55 | Distance from character center |
| `initialY` | 0–0.2 | Height the particle returns to on reset |
| `speed` | 0.5–1.5 | Rise velocity, units/second |
| `wobblePhase` | 0–2π | Lateral sway phase offset |
| `wobbleFreq` | 1.2–3.7 | Lateral sway frequency |

Every frame (`useLoop().onBeforeRender`) each particle rises by `speed * delta`, and its X/Z are placed on a cylinder of radius `radius + sin(elapsed * wobbleFreq + wobblePhase) * 0.05` that also rotates slowly (`angle + elapsed * 0.3`). When Y passes `RESET_Y`, the particle drops to `initialY`, gets a new `angle` and `radius`, and a new heat color from `heatColor(Math.random())`. `speed`, `wobblePhase` and `wobbleFreq` are kept.

If the rig is replaced while burning (a modular rig rebuild, for example), a second watch re-adds the points to the new rig.

## Animation Reaction

`flinch: true`, so the flinch loop runs:

| Parameter | Value |
|-----------|-------|
| Animation | `HIT_A` (flinch), crossfade `0.2` s |
| Interval | Every 3 seconds |
| Recovery animation | `SKELETONS_IDLE`, crossfade `0.3` s |
| Recovery delay | 800 ms |

The loop stops on removal and when the entity's `hp` reaches 0.
