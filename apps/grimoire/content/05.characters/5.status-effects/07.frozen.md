A magical crowd-control effect that encases the character in a crystalline ice pattern using a hex lattice shader overlay.

## Definition

`apps/playground/content/status-effects/frozen.yaml`:

```yaml
statusEffectId: frozen
label: Frozen
type: cc
armorGate: magical
color: text-cyan-300
bgColor: bg-cyan-900
icon: i-lucide-snowflake
flinch: false
```

::status-effect-badge{effect-id="frozen"}
::

## Sources

Only the command palette. Frozen **surface cells** (ice) inflict no status in v1 (`statusForCell` returns `null` when `cell.frozen`), so walking on ice does not freeze the character.

## Shader Overlay

<!-- TODO: Add screenshot of frozen overlay on character -->

The frozen overlay uses a hex lattice pattern generated from three cosine waves to create a crystalline ice effect:

| Parameter | Value |
|-----------|-------|
| Noise type | Hex lattice (3 cosine waves at ~60° angles) |
| Interior color | `#1144aa` (deep blue) |
| Edge color | `#aaddff` (cyan, the config `color`) |
| Flow speed | `0.0` (static) |
| Scale | `3.0` |
| Sharpness | `4.0` |
| Pulse speed | `0.4` |
| Intensity | `1.0` |

### Frost Spread

The effect uses a height mask that makes frost spread **upward from the ground**: `1 - smoothstep(0.8, 2.0, positionLocal.y)`. Full coverage at the feet, gradually fading above mid-torso. This creates the impression of ice creeping up from below.

### How It Works

`buildFrozenEmissiveNode(cfg)` in `@artificer-forge/vfx` generates the hex lattice in TSL by combining three cosine waves of `positionLocal * scale`, each mixing two axes with a `sqrt(3)` factor so they sit about 60° apart. The average is taken through `abs` and `pow(sharpness)` to sharpen the crystal-edge ridges. Interior and edge colors are mixed by that edge value, producing a faceted look similar to BG3's frozen effect. A `sin(time * 0.4)` pulse in `0.7..1.0` adds a gentle shimmer.

Priority: both `burning` and `poisoned` win over `frozen` when present.
