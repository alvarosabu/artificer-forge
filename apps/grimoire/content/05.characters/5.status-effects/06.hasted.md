---
title: Hasted
description: Speed buff badge, badge only, no movement speed code
---

A buff with a blue lightning-bolt badge. It is badge-only. Despite the name, nothing changes movement or animation speed.

## Definition

`apps/playground/content/status-effects/hasted.yaml`:

```yaml
statusEffectId: hasted
label: Hasted
type: buff
armorGate: none
color: text-blue-400
bgColor: bg-blue-900
icon: i-lucide-zap
flinch: false
```

::status-effect-badge{effect-id="hasted"}
::

## Sources

Only the command palette.

## What the code does with it

| Layer | Behavior |
|-------|----------|
| HUD | Badge in `Nameplate` and `CharacterPanel`; floating "Hasted" label from `useStatusEffectTexts` |
| Overlay | None |
| Particles | None |
| Animation | None (`flinch: false`) |
| Gameplay | None. `useCharacterController` takes a fixed `speed: 3` from `Character.vue` and does not read `statusEffects`. |

::note
If you add a speed modifier, the place to read the effect is `Character.vue`, where `useCharacterController(characterRef, { play }, { speed: 3 })` is created. The controller itself has no store access.
::
