A physical debuff that paints a pulsing toxic green aura over the model and makes the character flinch every 3 seconds.

## Definition

`apps/playground/content/status-effects/poisoned.yaml`:

```yaml
statusEffectId: poisoned
label: Poisoned
type: debuff
armorGate: physical
color: text-green-400
bgColor: bg-green-900
icon: i-lucide-skull
flinch: true
```

::status-effect-badge{effect-id="poisoned"}
::

## Sources

- Standing in a `poison` surface cell (`statusForCell` returns `poisoned`). The effect stays after the character leaves the pool.
- The command palette (**Add Status Effect**).

## Shader Overlay

The poisoned overlay uses Worley (cellular) noise to create a pulsing toxic aura:

:::div{class="grid grid-cols-2 gap-6 items-start"}

![Poisoned Overlay](/status/poisoned.gif)


| Parameter | Value |
|-----------|-------|
| Noise type | Worley cellular noise (`mx_worley_noise_float`) |
| Color | `#22ff44` (toxic green) |
| Flow direction | Upward (Y-axis) |
| Flow speed | `0.3` |
| Scale | `3.0` |
| Sharpness | `3.0` |
| Pulse speed | `1.5` |
| Intensity | `0.8` |

:::

The pattern slowly crawls up the character, creating a bubbling cellular texture that simulates poison coursing through the body.

### How It Works

`buildWorleyEmissiveNode(cfg)` in `@artificer-forge/vfx` samples Worley noise at `positionLocal * scale` with a time-based Y offset for upward flow. Local position, not UV, so the pattern is continuous across mesh seams. The cell value is inverted and raised to `sharpness`, then multiplied by a `sin(time * pulseSpeed)` pulse remapped to `0..1`. `useStatusEffectOverlay` assigns the result to the material's `emissiveNode`.

Priority: `burning` wins over `poisoned` when both are present.

## Animation Reaction

`flinch: true`, so `useStatusEffectAnimations` runs the flinch loop while the effect is present:

| Parameter | Value |
|-----------|-------|
| Animation | `HIT_A` (flinch), crossfade `0.2` s |
| Interval | Every 3 seconds |
| Recovery animation | `SKELETONS_IDLE`, crossfade `0.3` s |
| Recovery delay | 800 ms |

The loop stops on removal and when the entity's `hp` reaches 0.
