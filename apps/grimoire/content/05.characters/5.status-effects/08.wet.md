A debuff contracted from liquid surfaces. It is badge-only: no overlay, no particles, no animation, and no gameplay code reads it.

## Definition

`apps/playground/content/status-effects/wet.yaml`:

```yaml
statusEffectId: wet
label: Wet
type: debuff
armorGate: none
color: text-sky-300
bgColor: bg-sky-900
icon: i-lucide-droplets
flinch: false
```

::status-effect-badge{effect-id="wet"}
::

## Sources

- Standing in a `water` or `blood` cell that is not electrified and not frozen (`statusForCell`). If the pool is electrified the character gets `shocked` instead; if it is frozen, nothing.
- The command palette.

`wet` is not removed when the character leaves the pool. There is no duration system yet.

`warm` can coexist with `wet`: a character standing in water next to a fire gets both.

## What the code does with it

| Layer | Behavior |
|-------|----------|
| HUD | Badge in `Nameplate` and `CharacterPanel`; floating "Wet" label from `useStatusEffectTexts` |
| Overlay | None |
| Particles | None |
| Animation | None (`flinch: false`) |
| Gameplay | None. Fire does extinguish water **surfaces**, but a `wet` character is not protected from `burning`. |
