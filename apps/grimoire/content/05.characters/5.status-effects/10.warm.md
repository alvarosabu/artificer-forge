A buff for standing near fire. It is the only status the surface system both adds and removes each frame. Badge-only: no overlay, no particles, no animation, and no gameplay code reads it.

## Definition

`apps/playground/content/status-effects/warm.yaml`:

```yaml
statusEffectId: warm
label: Warm
type: buff
armorGate: none
color: text-orange-300
bgColor: bg-orange-950
icon: i-lucide-thermometer-sun
flinch: false
```

## Sources

`useSurface.tick` (`packages/engine/src/runtime/useSurface.ts`) checks every character every frame:

```ts
const isBurning = entity.statusEffects?.some(e => e.id === 'burning') ?? false
const inWarmRange = !isBurning
  && cell?.kind !== 'fire'
  && hasFireNear(grid.cellAt, col, row, FIRE_WARM_RADIUS)
if (inWarmRange) {
  gameStore.addStatusEffect(entity.id, 'warm')
}
else if (entity.statusEffects?.some(e => e.id === 'warm')) {
  gameStore.removeStatusEffect(entity.id, 'warm')
}
```

| Rule | Why |
|------|-----|
| Fire within `FIRE_WARM_RADIUS = 5` cells, disc test | Same disc as `stampDisc`, so the warm zone matches the fire's visual footprint |
| Not while standing on fire | Standing in fire gives `burning`; `warm` would be redundant |
| Never while `burning` is present | A contracted `burning` lingers after leaving the fire; the character should not read as "burning and cozy" |
| Removed when out of range | Radiant heat is proximity, not a contracted effect. Contracted statuses (`wet`, `slowed`, ...) have no removal yet. |

The `else if` guard avoids rewriting the entity object every frame for characters that were never warm.

The palette can also add it, but the surface tick removes it again on the next frame if there is no fire in range and the scene has an active surface field.

## What the code does with it

| Layer | Behavior |
|-------|----------|
| HUD | Badge in `Nameplate` and `CharacterPanel`; floating "Warm" label from `useStatusEffectTexts` (fires again each time the character re-enters range) |
| Overlay | None |
| Particles | None |
| Animation | None (`flinch: false`) |
| Gameplay | None |
