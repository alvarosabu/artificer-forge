---
title: Party HUD
description: PartyPanel and CharacterPanel, live-baked portrait, health, and armor for every party member
---

The party HUD is a vertical stack of portraits on the left edge of the screen. It is the player's at-a-glance status board and doubles as the click-target for selecting a character and opening their inventory.

## PartyPanel

A thin wrapper that iterates `gameStore.partyEntities` and renders one `CharacterPanel` per member. Drop it in any page that should show the party HUD; it positions itself fixed on the left edge.

`PartyPanel` and `CharacterPanel` ship from the engine's UI layer:

```ts
import { PartyPanel } from '@artificer-forge/engine/ui'
```

```vue
<template>
  <Game>
    <PartyPanel />
    <!-- … -->
  </Game>
</template>
```

```vue
<!-- packages/engine/src/ui/components/PartyPanel.vue -->
<script setup lang="ts">
import { computed } from 'vue'
import { useGameStore } from '@artificer-forge/engine/runtime'
import CharacterPanel from './CharacterPanel.vue'

const gameStore = useGameStore()
const partyMembers = computed(() => gameStore.partyEntities)
</script>

<template>
  <div class="fixed left-4 top-1/2 -translate-y-1/2 flex flex-col gap-2 z-50">
    <CharacterPanel
      v-for="member in partyMembers"
      :key="member.id"
      :member="member"
    />
  </div>
</template>
```

::note
`partyEntities` is a store getter. Adding or removing a member via `addToParty` / `removeFromParty` / `recruitEntity` / `dismissEntity` updates the panel reactively, no manual refresh needed.
::

## CharacterPanel

The single portrait card. Receives a full `EntityState` member and renders:

- the character's **live-baked portrait** inside a button,
- a "blood fill" overlay that rises from the bottom as HP drops,
- the `hp / maxHp` text, HP bar, and (when applicable) split armor bar,
- vertical status-effect badges to the right,
- a selection ring when the character is the currently-selected entity.

```vue
<CharacterPanel :member="entityState" />
```

### Portrait

The portrait is not the YAML `portrait` field. It comes from `usePortraitRenderer`, the same source as the ActionBar portrait and the nameplate thumbnail. The authored `portrait` is only the placeholder shown while the bake runs, or the fallback if it fails:

```ts
const { url: portrait } = usePortraitRenderer(() => props.member.id)
```

See [Portraits](/portraits/overview).

### Blood Fill

A red gradient overlay fills the portrait from below as the character takes damage. The fill height is `(1 - hp / maxHp) * 100`, clamped to `[0, 100]`, with a 700ms ease-out transition, so a hit makes the blood rise visibly.

```ts
const bloodFillPercent = computed(() => {
  const { hp, maxHp } = props.member
  if (!maxHp) return 0
  return Math.max(0, Math.min(100, (1 - (hp ?? 0) / maxHp) * 100))
})
```

### Selection and Click

Clicking the portrait selects the character (which also makes them the party leader, see [Actors](/actors/overview)) **and** opens the inventory focused on them:

```ts
function handleClick() {
  gameStore.selectEntity(props.member.id)
  inventory.open(props.member.id)
}
```

The selected portrait gains a white border with a glow:

```ts
isSelected
  ? 'border-white shadow-[0_0_8px_#ffffff]'
  : 'border-gold-400/30 hover:border-gold-400/60'
```

### Health and Armor Display

Underneath the portrait the panel renders a small stat strip:

| Element | Source | Condition |
|---------|--------|-----------|
| `hp / maxHp` text | `member.hp`, `member.maxHp` | always |
| Red HP bar | `member.hp` / `member.maxHp` | always |
| Split armor bar | `physicalArmor`, `magicalArmor` and `derivedMaxArmor` | `!isDead && hasArmor` |

`hasArmor` mirrors the nameplate's check: true when either derived max is `> 0`. See [Combat: Armor](/combat/armor) for the data model.

### Status Effect Badges

Status effects render as a vertical column to the right of the portrait, only when present.

```vue
<button>…</button>
<StatusEffectBadges
  v-if="member.statusEffects?.length"
  :status-effects="member.statusEffects"
  direction="col"
/>
```

## Drag-and-drop

`CharacterPanel` does not accept dropped items. Items are transferred through the inventory modal. The UI layer does ship a `PortraitDropZone` component (`@artificer-forge/engine/ui`, in `components/inventory/`) that wraps any element in a `useDropZone` and calls `gameStore.transferItem(draggedId, characterId)` on drop, but `CharacterPanel` does not use it. Wrap the card yourself if you want drop-to-give:

```vue
<PortraitDropZone :character-id="member.id">
  <CharacterPanel :member="member" />
</PortraitDropZone>
```

## Composition Summary

```
PartyPanel                       # fixed left edge, iterates partyEntities
└── CharacterPanel × N
    ├── button (live portrait + blood fill + bars)
    └── StatusEffectBadges       # vertical, to the right
```
