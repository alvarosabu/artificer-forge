---
title: Enemies
description: Hostile actors that stand idle, can be targeted by abilities, and carry equipment that feeds their armor pools
---

Enemies are actors on the `hostile` team. They are what abilities can target: `useCombatStore.hoverTarget` and `confirmTarget` accept only `team === 'hostile'` entities. They stand idle until hit.

## Characteristics

| Field | Value |
|-------|-------|
| `type` | `character` |
| `subtype` | `enemy` |
| `team` | `hostile` |
| `controllable` | `false` |
| Component | `Actor.vue` (or `Character.vue` when the page needs `showDamage` on them) |
| Behavior | `useActorBehavior` loops `ai.idleAnimation` (default `IDLE_A`) |

## Visual Distinctions

:::div{class="grid grid-cols-2 gap-6 items-start"}

- **Nameplate on hover**: red name with a skull icon <UIcon name="ph:skull-fill" class="size-4 text-white drop-shadow-[0_0_2px_#dc2626]" />, live portrait, `Lv. X · Race`, red HP bar, split armor bar when armored
- **Outline on hover**: the `hostile` outline preset (red)
- **Targeting**: while an ability is selecting, hovering an enemy shows a red `TargetReticle` at its feet; clicking confirms the target
- **Dead**: name replaced by `Dead`, greyed portrait, no bars

:::

## Equipment and armor

Enemies use the same equipment pipeline as the party. Items listed under `equipment` are spawned into the enemy's slots at spawn time, and `derivedMaxArmor` sums their `armor` blocks into the physical and magical pools that `applyDamage` drains first. The orc scout carries a breastplate and a ring, so a fireball must burn through 3 magical armor before it touches HP:

```yaml
equipmentSlots:
  - mainHand
  - armor
  - ring1

equipment:
  mainHand: orc_axe
  armor: breastplate
  ring1: ring-of-warding
```

See [Combat: Armor](/combat/armor).

## `ai` and `drops` are data only

The orc scout template declares an aggressive AI and a drop table:

```yaml
ai:
  behavior: aggressive
  alertRange: 10
  attackRange: 5
  fleeThreshold: 0.2

drops:
  - id: gold
    quantity: [1, 5]
    chance: 0.8
  - id: dagger_rusty
    chance: 0.2
```

::warning
No code reads `behavior: aggressive`, `alertRange`, `attackRange`, `fleeThreshold` or `drops`. Enemies do not notice, pursue, attack or flee, and defeating one does not roll the drop table. `useActorBehavior` only reads `ai.idleAnimation`. Treat these fields as authored intent for a future AI and loot pass. Corpse looting today goes through the entity's own inventory container, see [Inventory: Loot](/inventory/loot).
::

## Orc Scout

An orc with an axe, a breastplate and a ring of warding. `apps/playground/content/entities/characters/enemies/orc_scout.yaml`:

```yaml
templateId: orc_scout
type: character
subtype: enemy
name: Orc Scout
level: 1
race: Orc
faction: orc
team: hostile
controllable: false
model: /models/characters/orc.glb
rig: Rig_Medium
animations:
  idle: Idle
  walk: Walk
  run: Run
  attack: Slash
equipment:
  mainHand: orc_axe
  armor: breastplate
  ring1: ring-of-warding
```

The combat playground spawns it opposite the leader:

```ts
// apps/playground/pages/combat/attack/experience.vue
const heroId = await gameStore.spawnFromTemplate('cedric', { x: -1.5, y: 0, z: 0 })
gameStore.addToParty(heroId)
gameStore.selectEntity(heroId)
await gameStore.spawnFromTemplate('orc_scout', { x: 1.5, y: 0, z: 0 })
```
