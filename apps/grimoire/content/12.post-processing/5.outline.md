::warning
The outline **render pass is disabled**. The per-preset `outline()` loop in `EffectComposer.vue` (lines 119-148) has been commented out since commit `660fbd0` (2026-08-26), and the build log prints `outline: 'disabled'`. The selection API below still works and the engine still calls it, but no edge is drawn on screen. The `outlinePresets` prop is accepted and ignored.
::

## Selection API

`packages/post-processing/src/useOutlinePass.ts` keeps named groups of objects. The composer was designed to build one outline pass per group, so a group name is the same key as a preset in `outlinePresets`.

```ts
export interface OutlinePassApi {
  getGroup: (name: string) => ShallowRef<Object3D[]>
  addToSelection: (object: Object3D, group?: string) => void
  removeFromSelection: (object: Object3D, group?: string) => void
}
```

| Function | Returns | Notes |
|----------|---------|-------|
| `useOutlinePassProvider()` | `OutlinePassApi` | Creates the group map and `provide`s it under `OutlinePassKey`. `<Game>` calls it once. |
| `useOutlinePass()` | `OutlinePassApi` | `inject(OutlinePassKey)`. **Throws** `useOutlinePass must be used within a Game component` when no provider exists. |
| `getGroup(name)` | `ShallowRef<Object3D[]>` | Creates the group on first access. |
| `addToSelection(object, group = 'default')` | `void` | No-op if already present. Replaces the array so watchers fire. |
| `removeFromSelection(object, group = 'default')` | `void` | No-op if absent. |

The object type is `any` in the source to avoid three type mismatches between packages.

### Engine consumers

These calls run today and keep the groups in sync, ready for the pass to be re-enabled:

| Component | Group | When |
|-----------|-------|------|
| `Character.vue` | `'hostile'` | Pointer enters a hostile entity while `combatStore.isTargeting`. |
| `Character.vue` | `'party'` | Pointer enters a non-selected party member outside targeting. |
| `Actor.vue` | `entity.team ?? 'neutral'` | Pointer enter / leave. |
| `Interactable.vue` | `'interactive'` | Pointer enter / leave on the interactable's scene root. |

```ts
const { addToSelection, removeFromSelection } = useOutlinePass()

function handlePointerEnter() {
  if (scene.value) addToSelection(scene.value, 'interactive')
}
function handlePointerLeave() {
  if (scene.value) removeFromSelection(scene.value, 'interactive')
}
```

## Presets

The package `OutlinePreset` has five optional fields. The composer defaults (in the commented-out code) were:

| Name | Type | Default | Purpose |
|------|------|---------|---------|
| `visibleEdgeColor` | `string` | `'#ffffff'` | Colour of edges in front of other geometry. |
| `hiddenEdgeColor` | `string` | `'#4e3636'` | Colour of edges behind other geometry. |
| `edgeStrength` | `number` | `3` | Multiplier on the composed edge colour. |
| `edgeThickness` | `number` | `1` | Edge width in pixels. |
| `edgeGlow` | `number` | `0` | Extra glow around the edge. |

The engine's own `OutlinePreset` (`useGameConfig.ts`) is narrower. It has only `visibleEdgeColor` and `edgeThickness`, and `defaultGameConfig()` ships five presets named after the selection groups:

```ts
outlinePresets: {
  party: { visibleEdgeColor: '#00e5ff', edgeThickness: 3 },
  interactive: { visibleEdgeColor: '#ffcc00', edgeThickness: 3 },
  hostile: { visibleEdgeColor: '#ff4444', edgeThickness: 3 },
  neutral: { visibleEdgeColor: '#ffffff', edgeThickness: 3 },
  ally: { visibleEdgeColor: '#00e5ff', edgeThickness: 3 },
}
```

## How the pass worked, and where it would sit

For each `[name, preset]` in `outlinePresets` the composer built an `outline(scene, camera, { selectedObjects, edgeGlow, edgeThickness })` node, coloured `visibleEdge` and `hiddenEdge` with uniforms, multiplied by `edgeStrength`, and summed all presets into `composedOutline`. A watcher on `getGroup(name)` copied the group into the pass's `selectedObjects` array. `composedOutline` was then added to the scene colour **after** DoF and **before** bloom, so edges stayed sharp and did not glow.

Re-enabling it means uncommenting that loop. Expect a cost: each preset is an extra scene render for the selection mask.
