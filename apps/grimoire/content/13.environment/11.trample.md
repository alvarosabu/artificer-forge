A trample map is a world-aligned `CanvasTexture`. Characters stamp white discs into it every frame, it fades back to black over time, and every vegetation component samples it in the vertex shader to flatten blades and squash bushes where it is marked. A second, cheaper signal, the `interactor` position, pushes blades away from the party leader in real time.

```ts
import { createTrampleMap, trampleUv, worldToPixel } from '@artificer-forge/engine/runtime'
import type { TrampleMap, TrampleSettings, TrampleUniforms } from '@artificer-forge/engine/runtime'
```

## Usage

Trimmed from `apps/playground/pages/environment/foliage/experience.vue`:

```vue
<script setup lang="ts">
import { createTrampleMap, Foliage, Grass, useGameStore, useSceneRefs } from '@artificer-forge/engine/runtime'

const gameStore = useGameStore()
const { getCharacterRef } = useSceneRefs()
const characterEntities = computed(() =>
  [...gameStore.entities.values()].filter(e => e.type === 'character'))

// world-aligned trample map: characters stamp it, grass/foliage bend where it's marked
const trampleMap = createTrampleMap({ size: 30, resolution: 256 })

const { onBeforeRender } = useLoop()
onBeforeRender(({ delta }) => {
  trampleMap.update(delta)
  for (const entity of characterEntities.value) {
    const pos = getCharacterRef(entity.id)?.getPosition()
    if (pos) trampleMap.stamp(pos.x, pos.z)
  }
  const leaderPos = gameStore.selectedEntityId
    ? getCharacterRef(gameStore.selectedEntityId)?.getPosition()
    : null
  if (leaderPos) trampleMap.setInteractor(leaderPos.x, leaderPos.z)
})

onUnmounted(() => trampleMap.dispose())
</script>

<template>
  <Foliage :references="references" :trample="trampleMap" />
  <Grass :trample="trampleMap" />
</template>
```

The terrain experience uses `createTrampleMap({ size: 60, resolution: 512 })` and runs the stamp loop at priority 10, so it lands where the character is NOW, not last frame.

## `createTrampleMap(settings)`

```ts
function createTrampleMap(settings?: TrampleSettings): TrampleMap
```

| Setting | Type | Default | Purpose |
|---------|------|---------|---------|
| `size` | `number` | `30` | World extent covered (width = depth), centred on `origin` |
| `resolution` | `number` | `256` | Texels per side |
| `recovery` | `number` | `0.4` | Trample fraction removed per second (spring-back speed) |
| `stampRadius` | `number` | `0.9` | Default stamp radius in world units |

It throws `[trample] 2d canvas context unavailable` when there is no 2D context (SSR, headless without canvas).

### `TrampleMap`

| Member | Type | Purpose |
|--------|------|---------|
| `texture` | `CanvasTexture` | Red channel = trample amount, 0..1. `ClampToEdgeWrapping` |
| `uniforms.origin` | `UniformNode<vec2>` | World XZ of the map centre, default `(0, 0)` |
| `uniforms.size` | `UniformNode<float>` | World extent |
| `uniforms.interactor` | `UniformNode<vec2>` | Leader position. Parked at `(1e6, 1e6)` until the first `setInteractor`, so it is inactive by default |
| `uniforms.interactorRadius` | `UniformNode<float>` | Push radius, `1.2`. Set `.value` to change it |
| `stamp(x, z, strength?, radius?)` | | Paint a radial gradient disc (`strength` default `1`, `radius` default `stampRadius`) and flag the texture for upload |
| `setInteractor(x, z)` | | Move the push centre |
| `setOrigin(x, z)` | | Move the map. Existing pixels stay where they are in texture space |
| `update(delta)` | | Fade toward black. Call once per frame |
| `dispose()` | | Disposes the texture |

### Fade

`update` accumulates `recovery * delta` into a carry and only applies the black fill once the carry reaches `MIN_FADE_ALPHA = 6 / 255`. Smaller alphas stall on 8-bit rounding and would never clear. The multiplicative fade leaves about 5% residual in old trails, invisible under wind sway.

### Coordinate mapping

```ts
trampleUv(uniforms, worldXZ)   // TSL: (worldXZ - origin) / size + 0.5
worldToPixel(x, z, originX, originZ, size, resolution) // CPU: { x: u * resolution, y: (1 - v) * resolution }
```

`CanvasTexture` flips Y (`v = 1` is canvas row 0), so `+z` maps to DECREASING pixel y. `trample.test.ts` pins this: the origin maps to the canvas centre, `+x` to increasing pixel x, `+z` to decreasing pixel y, and both shift with the origin.

## How components consume it

Every consumer samples `texture(trample.texture, trampleUv(trample.uniforms, worldXZ)).r` once per instance in the vertex stage, then applies it in species-specific amounts:

| Component | Flatten | Wind damping | Interactor push |
|-----------|---------|--------------|-----------------|
| [Foliage](/environment/foliage) | Anchor `y *= 1 - 0.6 * t` (squash toward the ground) | none | none |
| [Grass](/environment/grass) | `height *= 1 - 0.75 * t` | `wind *= 1 - t` | `push² * 0.5 * windWeight`, tip drops `0.3 * height` |
| [GrassTufts](/environment/grass#grasstufts) | `height *= 1 - 0.55 * t` (stiffer) | `wind *= 1 - t` | `push² * 0.4 * bladeT`, drops `0.25 * height` |
| [Flowers](/environment/flowers) | `stemHeight *= 1 - 0.85 * t` | `wind *= 1 - t` | `push² * 0.5 * windWeight`, drops `0.3 * height` |
| [Trees](/environment/trees) | none, on purpose | | |

The interactor push is `push = max(0, 1 - dist / interactorRadius)`, applied along the XZ direction from the interactor to the blade. It is independent of the stamped texture, so blades part around the leader the instant they move, while the texture records the trail behind them.

## Debug view

The texture's backing canvas can be shown live. All three playground experiences expose a `trample.debug` leches toggle that pins it to the bottom-right corner:

```ts
const trampleCanvas = trampleMap.texture.image as HTMLCanvasElement
watch(trampleDebug, (show) => {
  if (show) {
    Object.assign(trampleCanvas.style, { position: 'fixed', bottom: '16px', right: '16px', width: '200px', height: '200px', pointerEvents: 'none' })
    document.body.appendChild(trampleCanvas)
  }
  else {
    trampleCanvas.remove()
  }
})
onUnmounted(() => { trampleCanvas.remove(); trampleMap.dispose() })
```

## Gotchas

::warning
- **Every fade frame re-uploads the whole canvas.** A 512² map is 1 MB per upload. Drop the resolution before anything else if it bites.
- **Stamp after movement.** Register the stamp loop with the same or a later `useLoop` priority as the character controller, or the trail lags one frame behind the feet.
- **The map does not move with the party.** `size` is a fixed world square around `origin`. Walk outside it and the clamp-to-edge border repeats the last texel. Enlarge `size` or call `setOrigin` when the level shifts.
- **Not for canopies.** Foliage squashes anchors toward y = 0. Under a tree that is several metres of air.
- **Passing the map is a creation-time decision.** Like `grading`, the node graph bakes in whether `trample` exists. Remount to add or remove it.
::
