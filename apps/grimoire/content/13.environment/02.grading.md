Grading IS the lighting. A graded material is unlit: `stylizedOutput` takes the material's base colour and produces the final pixel itself (light tint, a colour ramp for the core shadow, drop shadows folded into the same band, fog). One `GradingContext` holds the uniforms, every material in the scene reads them, and a day cycle re-grades the whole world by writing eight values per frame. The approach is adapted from Bruno Simon's Folio 2025.

```ts
import { createGradingContext, stylizedOutput, createDropShadowCatcher, applyGradingToModel } from '@artificer-forge/engine/runtime'
import type { GradingContext, GradingProps, StylizedOutputOptions } from '@artificer-forge/engine/runtime'
```

## `createGradingContext(options)`

```ts
function createGradingContext(options: { sceneNear: number, sceneFar: number }): GradingContext
```

`sceneNear` and `sceneFar` are distances in metres. A preset gives fog near/far as ratios of this span, so you tune the span by where you want the haze to land, not per preset. The day-cycle experience uses `{ sceneNear: 12, sceneFar: 45 }`; the terrain level uses `{ sceneNear: 50, sceneFar: 1000 }`.

It returns:

| Property | Type | Purpose |
|----------|------|---------|
| `uniforms` | see table below | 22 TSL uniforms. Materials read them; `sync` writes the first eight |
| `fogColor` | `Node<'vec3'>` | Screen-space radial gradient between `fogColorA` and `fogColorB`. Also the sky: assign it to `scene.backgroundNode` |
| `fogStrength` | `Node<'float'>` | `rangeFogFactor(fogNear, fogFar)` |
| `sync(props)` | `(props: GradingProps) => void` | Copies a `GradingProps` into the uniforms. Call once per frame |
| `range` | `{ sceneNear, sceneFar }` | Mutable. `sync` reads it every call, so a leches slider can retune the span live |

### `GradingProps`

The eight values a preset or the [environment store](/environment/environment-store) supplies:

| Name | Type | Purpose |
|------|------|---------|
| `lightDirection` | `Vector3` | Normalized, pointing FROM the light INTO the scene. `(-1, -1, -1).normalize()` is the classic diagonal |
| `lightColor` | `Color` | Multiplies every base colour |
| `lightIntensity` | `number` | Multiplies every base colour |
| `shadowColor` | `Color` | Core shadows mix toward `baseColor * shadowColor`, never toward black. It is a multiplier, so keep it bright and desaturated (day preset: `#b4a0c8`) |
| `fogColorA` | `Color` | Gradient centre (horizon) |
| `fogColorB` | `Color` | Gradient edge (zenith) |
| `fogNearRatio` | `number` | -2..2, ratio of the `sceneNear..sceneFar` span. Negative means fog starts behind the camera |
| `fogFarRatio` | `number` | Same scale |

`sync` maps the ratios: `fogNear = sceneNear + fogNearRatio * (sceneFar - sceneNear)`, same for far.

### Uniforms

| Uniform | Type | Default | Written by | Purpose |
|---------|------|---------|------------|---------|
| `lightDirection` | `vec3` | `(-1,-1,-1)` normalized | `sync` | Core shadow facing, specular half vector |
| `lightColor` | `color` | `#ffffff` | `sync` | Light tint, rim and specular colour |
| `lightIntensity` | `float` | `1` | `sync` | Light tint |
| `shadowColor` | `color` | `#000000` | `sync` | Core, AO and drop shadow tint |
| `fogColorA` | `color` | `#88aaff` | `sync` | Gradient centre |
| `fogColorB` | `color` | `#4455aa` | `sync` | Gradient edge |
| `fogNear` | `float` | `sceneNear` | `sync` | Range fog start (metres) |
| `fogFar` | `float` | `sceneFar` | `sync` | Range fog end (metres) |
| `radialCenter` | `vec2` | `(0.5, 0.5)` | you | Gradient centre in `viewportUV` |
| `radialStart` | `float` | `0` | you | Distance where the gradient leaves `fogColorA` |
| `radialEnd` | `float` | `1` | you | Distance where it reaches `fogColorB` |
| `shadowEdgeLow` | `float` | `0` | you | Core shadow ramp start on `normal · lightDirection` |
| `shadowEdgeHigh` | `float` | `0.25` | you | Core shadow ramp end. A tight band reads as a cel step |
| `midEdgeLow` | `float` | `-0.35` | you | Mid-tone band start (`hasMidTone`) |
| `midEdgeHigh` | `float` | `-0.15` | you | Mid-tone band end |
| `midStrength` | `float` | `0.5` | you | How far the mid tone leans toward the shadow colour |
| `rampHardness` | `float` | `0` | you | 0 = smoothstep bands, 1 = hard `step()` at each band centre (Wind Waker cel) |
| `rimStrength` | `float` | `0.25` | you | Fresnel rim amount (`hasRim`) |
| `rimPower` | `float` | `3` | you | Fresnel exponent |
| `aoStrength` | `float` | `1` | you | Global scale on `aoNode`. 0 disables AO everywhere |
| `specStrength` | `float` | `0` | you | Toon specular amount (`hasSpecular`). Off by default: without gloss masks it hits skin and cloth and reads plastic |
| `specShininess` | `float` | `32` | you | Specular exponent |

The last 14 are shape knobs, not per-preset values. Drive them straight from leches like the day-cycle experience does:

```ts
const { rampShadowLow, rampHardness } = useControls('ramp', {
  shadowLow: { value: 0, min: -1, max: 1, step: 0.01, type: 'range' },
  hardness: { value: 0, min: 0, max: 1, step: 0.01, type: 'range' },
}, { uuid })
watch(rampShadowLow!, (v) => { grading.uniforms.shadowEdgeLow.value = v })
watch(rampHardness!, (v) => { grading.uniforms.rampHardness.value = v })
```

## Wiring a scene

Three things, all from `apps/playground/pages/environment/day-cycle/experience.vue`:

```ts
const environment = useEnvironmentStore()
const grading = createGradingContext({ sceneNear: 12, sceneFar: 45 })

// 1. the sky is the fog gradient
const { scene } = useTresContext()
watch(scene, (s) => {
  if (!s) return
  s.background = null                 // never leave a texture fighting the node
  s.backgroundNode = grading.fogColor
}, { immediate: true })

// 2. copy the store into the uniforms every frame
const { onBeforeRender } = useLoop()
onBeforeRender(() => {
  grading.sync(environment) // store keys match GradingProps structurally
  syncLights()
})

// 3. the shadow-map light must aim along grading.lightDirection
function syncLights() {
  const directional = directionalLightRef.value
  if (!directional) return
  directional.color.copy(environment.lightColor)
  directional.intensity = 1.2 * environment.lightIntensity
  directional.position.copy(environment.lightDirection).multiplyScalar(-20)
}
```

Then pass `:grading="grading"` to every component: `<Floor>`, `<Foliage>`, `<Grass>`, `<Character>`, `<TerrainQuadtree>`, `<Water>`.

::note
Step 3 matters. Drop shadows come from the three.js shadow map, so the `DirectionalLight` is still needed. But if its direction drifts from `lightDirection`, the cast shadow and the core shadow disagree about where the sun is. The terrain experience has no ambient light at all: graded materials discard the lighting result, so the sun only drives the shadow map.
::

## `stylizedOutput(baseColor, grading, options)`

```ts
function stylizedOutput(baseColor: Node, grading: GradingContext, options?: StylizedOutputOptions): Node<'vec4'>
```

Assign the result to `material.outputNode`. The graph runs in this order:

1. `out = baseColor * lightColor * lightIntensity`
2. `facing = normal · lightDirection`, `shadowMix = ramp(shadowEdgeLow, shadowEdgeHigh)` when `hasCoreShadows`
3. `aoNode` and `dropShadowNode` are folded into `shadowMix` with `max`, so AO and cast shadows land in the SAME band as the core shadow. The palette stays two-tone and re-grades with the cycle (a black multiply would not).
4. Optional mid tone, then `out = mix(out, baseColor * shadowColor, shadowMix)`
5. Optional specular (masked out of the shadow band) and rim
6. Fog: `out = fogStrength.mix(out, fogColor)` when `hasFog`
7. Alpha: with `alphaTest`, discard below it and return alpha 1; otherwise return `alphaNode`

| Option | Type | Default | What it toggles |
|--------|------|---------|-----------------|
| `hasFog` | `boolean` | `true` | Step 6 |
| `hasCoreShadows` | `boolean` | `true` | The `normal · lightDirection` ramp. Grass, tufts and flowers set it `false`: bent-blade normals are noisy |
| `dropShadowNode` | `Node<'float'>` | none | `shadowFactor` from `createDropShadowCatcher` (1 lit, 0 shadowed). Folded into the shadow band |
| `hasMidTone` | `boolean` | `false` | 3-zone ramp (lit / mid / shadow) using `midEdgeLow`, `midEdgeHigh`, `midStrength`. Only with `hasCoreShadows`. For smooth geometry that reads flat on two tones |
| `hasRim` | `boolean` | `false` | Fresnel edge glow tinted by `lightColor` |
| `hasSpecular` | `boolean` | `false` | Stepped toon highlight (`pow(specShininess).smoothstep(0.3, 0.5)`) on the lit side only |
| `normalNode` | `Node<'vec3'>` | `normalWorld` | World-space normal for the ramp |
| `aoNode` | `Node<'float'>` | none | Occlusion, 1 open / 0 occluded. Scaled by `aoStrength`, folded into the shadow band |
| `alphaNode` | `Node<'float'>` | `float(1)` | Coverage |
| `alphaTest` | `number` | none | Discard threshold applied AFTER fog |

Minimal adopter (this is what `Floor.vue` does):

```ts
const material = new MeshLambertNodeMaterial()
const dropShadow = createDropShadowCatcher()
material.receivedShadowNode = dropShadow.receivedShadowNode
material.outputNode = stylizedOutput(gridColor, grading, {
  hasCoreShadows: false,
  dropShadowNode: dropShadow.shadowFactor,
})
```

## `createDropShadowCatcher()`

```ts
function createDropShadowCatcher(): { shadowFactor: Node<'float'>, receivedShadowNode: Fn }
```

Shadow-map sampling only runs inside a LIT material's lighting pipeline. The catcher hooks `receivedShadowNode`, multiplies the sampled shadow into `shadowFactor`, and returns `1` so the built-in black multiply is neutralized. `stylizedOutput` then re-applies the shadow as a tint toward `shadowColor` via `dropShadowNode`.

This is the reason every graded material is a `MeshLambertNodeMaterial`. The Lambert lighting result itself is thrown away by `outputNode`; the material is lit ONLY so the catcher executes. A `MeshBasicNodeMaterial` never samples the shadow map, so `shadowFactor` stays at 1 and the object receives no shadows.

## `applyGradingToModel(root, grading, options)`

```ts
function applyGradingToModel(root: Object3D, grading: GradingContext, options?: { groundHeight?: Node<'float'> }): void
```

Converts a loaded GLB (characters, props) to the graded finish. For every mesh under `root`:

- Skips material arrays, materials already marked `userData.graded`, and custom node materials (ghost arm, horns keep their own look).
- Builds a `MeshLambertNodeMaterial` with `baseColor = texture(map).rgb * color` (or the colour alone), `side` copied from the source.
- Approximates AO because the GLBs bake none: `skyAo` darkens down-facing surfaces, `contactAo` darkens the 0.35 m above `groundHeight`, multiplied by `aoMap` when present.
- Calls `stylizedOutput` with `hasMidTone`, `hasRim`, `hasSpecular` all on, plus the AO and a drop-shadow catcher.
- Caches the graded material on `source.userData.gradedMaterial` and swaps it in.

It is safe to re-run on the same tree. A cache built for another `grading` or another `groundHeight` is disposed and rebuilt, because both are baked into the graph and the loader cache shares GLB materials across scenes.

`<Character>` calls it for you through two props:

```vue
<Character :entity-id="entity.id" :grading="grading" :ground-height="characterGroundHeight" />
```

`groundHeight` defaults to flat ground at y = 0. On terrain pass `sampleHeight(field, positionWorld.xz)` or the model darkens as if buried. The terrain experience does the same for level props: `applyGradingToModel(root, grading, { groundHeight: ground })`.

::warning
The base colour is a snapshot taken at first build. A later change to `MeshStandardMaterial.color` on the source is not tracked. `Character.vue` registers its grading watcher AFTER `useModularRig` so the skin and hair tint effects run first in the same flush, and it grades equipment inside `useEquipment`'s `onAttach` so attached parts are covered too.
::

## Fog and sky

There is no `TresFog` and no `scene.fog`. Fog is part of the finish:

- `fogColor` is a screen-space gradient: `dist = length(viewportUV - radialCenter)`, `mix(fogColorA, fogColorB, dist.smoothstep(radialStart, radialEnd))`. Centre is the horizon colour, edge is the zenith colour.
- `fogStrength` is `rangeFogFactor(fogNear, fogFar)`, linear in view distance.
- The same `fogColor` is the background (`scene.backgroundNode = grading.fogColor`). Distant geometry dissolves into exactly the colour behind it, so there is no horizon seam.
- Negative `fogNearRatio` is allowed and used: the night preset has `-0.85`, so the fog plane starts behind the camera and the whole scene sits in haze.

## Gotchas

::warning
- **`MeshLambertNodeMaterial` or no drop shadows.** See the catcher section. `Floor`, `Foliage`, `Grass`, `GrassTufts`, `Flowers` and `applyGradingToModel` all switch to Lambert only when `grading` is set.
- **Cutouts go through `stylizedOutput`, not `material.alphaTest`.** Pass `alphaNode` and `alphaTest` in the options. The discard runs AFTER fog, so cutout edges do not pop against the haze. The finish also returns alpha 1 for surviving pixels on purpose: a smooth alpha leaks into the canvas alpha channel, and a premultiplied canvas (`alpha: true`) then composites the page background through every leaf edge as a white halo. Foliage skips `opacityNode` and `material.alphaTest` entirely on the graded path.
- **`discard()` is a statement.** `stylizedOutput` wraps its body in `Fn(() => ...)()` because a discard only registers on an active TSL stack. Do the same in your own graphs.
- **`grading` is decided at creation.** Every component builds one of two node graphs. Toggling the prop after mount does nothing; remount instead.
- **Ambient light does nothing to graded materials.** The Lambert result is discarded. Keep ambient lights for PBR props and portrait captures only.
- **`setGrading` mutates `Color` objects in place.** Template bindings cannot track that. Copy the store into the uniforms and the shadow light per frame (`grading.sync(environment)`, `syncLights()`), not in a `watch`.
- **`uniform()` wants raw three.js values.** Pass `new Color(...)` or `new Vector3(...)`, never a TSL `color()` / `vec3()` node, or the GPU buffer ends up zero-sized.
::
