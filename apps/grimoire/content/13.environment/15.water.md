title: Water
description: The Water component and buildWaterMaterial, a flat plane that reads the frame and depth buffer behind it, absorbs light per metre of water, adds foam bands, ripple refraction and sun glitter, and why it needs an opaque canvas.
---

`<Water>` is one flat quad the size of the [control map](/environment/terrain-heightmap#control-map). The material writes **no colour of its own**. It reads whatever is already in the framebuffer behind the plane (`viewportSharedTexture`), measures how much water the view ray crossed from the depth buffer (`viewportLinearDepth`), and eats light out of the backdrop in proportion. Shallow edges stay near the ground colour; deep parts go blue-green. Foam, ripples and sun glitter sit on top.

```ts
import { Water, buildWaterMaterial, createWaterUniforms } from '@artificer-forge/engine/runtime'
```

## `<Water>`

| Prop | Type | Default | Purpose |
|------|------|---------|---------|
| `control` | `ControlMap` | required | Blue channel is the surface mask, and `control.size` is the quad size. |
| `normalMap` | `Texture` | `undefined` | Tangent-space normal map for ripples and refraction. Without it the surface is flat (`normal = (0, 1, 0)`). |
| `level` | `number` | `-0.35` | World Y of the plane. Must match the terrain's `waterLevel` uniform or the damp shore ring detaches. |
| `grading` | `GradingContext \| null` | `undefined` | Enables sun glitter and fog convergence. See [Grading](/environment/grading). |
| `uniforms` | `WaterUniforms` | own bag | `createWaterUniforms()` bag. Write `.value` to retune without a rebuild. |

Exposes `{ uniforms }`. The geometry is `PlaneGeometry(control.size, control.size, 1, 1)` rotated flat and positioned at `level`. The mask decides where it reads as water, so the quad can cover the whole level.

## buildWaterMaterial

```ts
const { material, uniforms } = buildWaterMaterial({ control, grading, normalMap, uniforms })
```

| Option | Type | Default | Purpose |
|--------|------|---------|---------|
| `control` | `ControlMap` | required | Mask source. |
| `grading` | `GradingContext \| null` | `undefined` | Sun and fog. |
| `normalMap` | `Texture` | `undefined` | Prepared once: `RepeatWrapping`, `NoColorSpace`, `anisotropy = 4`. |
| `uniforms` | `WaterUniforms` | `createWaterUniforms()` | Shared knob bag. |

Returns a `MeshBasicNodeMaterial` with `transparent = true` and `depthWrite = false`. `transparent` is there to put the draw in the **transparent queue**, after every opaque object, so the framebuffer and depth buffer it reads are already full. `depthWrite = false` because a transparent surface above opaque ground that wrote depth would hide itself.

## How the shader works

Everything happens in one `outputNode`. In order:

1. **Mask.** `mask = smoothstep(maskLow, maskHigh, control.b)`. It becomes the output alpha. Inside the lake it is 1 and the blend is a no-op; along the shore it ramps to 0 so the edge is not a cut line.
2. **Ripple normal.** Two layers of the normal map at `rippleScale` and `rippleScale * 1.63`, drifting in different directions at `rippleSpeed`. They are combined with a whiteout blend (tilts add, ups multiply) and scaled by `rippleStrength`. Averaging the vectors would cancel them wherever they disagree and flatten the surface.
3. **Straight depth.** `straightDepth = (viewportLinearDepth - linearDepth()) * (cameraFar - cameraNear)`, clamped at 0. Both depth nodes return 0..1 across the camera range, so the multiply turns the difference into metres along the view ray. This value drives the shore fade and all of the foam.
4. **Refraction.** `offset = normal.xz * refraction * smoothstep(0, 0.6, straightDepth) / eyeDistance`. The divide by distance matters: a world-sized ripple becomes a screen-space offset, and without it the far shore refracts as hard as the water at your feet. `backdrop = viewportSharedTexture(screenUV + offset).rgb`.
5. **Through-water depth.** Read again at the refracted uv: `throughWater = (linearDepth(viewportDepthTexture(refractUv)) - surfaceDepth) * span`, clamped to `0..maxDepth`. The `maxDepth` cap is what keeps sky pixels from going black: behind the plane the depth buffer holds the far plane, which would be a kilometre of water.
6. **Absorption.** Beer-Lambert, one exponent per channel: `out = backdrop * exp(-absorption * absorbStrength * throughWater)`. `absorption` is the colour the water **eats**, not the colour it looks. The reddish-orange default removes red fastest, and what survives reads blue-green.
7. **Foam.** Computed before grading on purpose, so it fogs with everything else instead of burning white lines through the haze.
   - `shallow = straightDepth * |toEye.y|` converts the along-ray distance back to vertical metres. Without it the band fattens as you lower the camera.
   - `wobble = (normal.x + normal.z) * foamWobble`, signed, so the band breathes in and out. `normal.xz.length()` is the tempting version and can only push it out to sea.
   - `shoreT = clamp((shallow + wobble) / foamDepth)`, 0 at the waterline, 1 at `foamDepth` metres.
   - Stripes: `fract(shoreT * foamLines + time * foamDrift + 0.5)` folded into a triangle wave and thresholded by `foamWidth`. `+ time` sends the stripes toward the beach. The `+0.5` puts the first stripe on the waterline.
   - Rim: `1 - smoothstep(0, foamEdge, shoreDepth)`, a solid band hugging the contact line.
   - `foam = max(stripes * (1 - shoreT), rim)`. The `(1 - shoreT)` envelope stops the outermost stripe ending on a hard line in open water; `max` instead of `add` keeps the overlap of rim and first stripe from clipping flat white.
   - `out = mix(out, foamColor, foam)`. The foam colour's brightness **is** the strength, which is why there is no separate uniform. It is deliberately not pure white: at `#ffffff` the sun glitter has nowhere left to go exactly where the surface is brightest.
8. **Sun glitter** (grading only). Blinn-Phong half vector against the ripple normal: `sun = dot(normal, half)^sunSharpness * sunStrength`, tinted by `lightColor * lightIntensity`, multiplied by `(1 - foam)` because churned water is rough and has no mirror. `lightDirection` points from the light into the scene, so it is negated first.
9. **Fog** (grading only). `out = mix(out, backdrop, fogStrength)`. Not toward `fogColor`: the backdrop already carries the terrain's fog, so fogging again would haze the lake faster than the ground it sits in. Converging on the backdrop lands on the correctly fogged pixel.
10. `return vec4(out, mask)`.

::tip
`straightDepth` and `throughWater` are differences of depths normalised across `cameraNear..cameraFar`. A very large far plane spends the depth buffer's precision on distance you never see and shows up as banding in the shallows. Keep the camera range close to the level size.
::

## createWaterUniforms

18 uniforms.

| Family | Uniform | Default | Purpose |
|--------|---------|---------|---------|
| Body | `absorption` | `#ff5a1e` | Colour eaten per metre. The surface reads as its complement. |
| | `absorbStrength` | `0.55` | How hard absorption bites per metre travelled. |
| | `maxDepth` | `8` | Metres after which the ramp stops deepening. Also the sky guard. |
| Mask | `maskLow` | `0.04` | `control.b` where the surface starts. |
| | `maskHigh` | `0.28` | `control.b` where it is fully water. |
| Ripples | `rippleScale` | `0.35` | Normal-map tiles per metre. |
| | `rippleStrength` | `0.6` | Tilt of the combined normal. |
| | `rippleSpeed` | `0.04` | Drift speed. |
| | `refraction` | `0.6` | Screen-space offset scale. |
| Sun | `sunStrength` | `1.4` | Glitter brightness (grading only). |
| | `sunSharpness` | `180` | Specular exponent. High on purpose: a soft sheen reads as plastic. |
| Foam | `foamColor` | `#e8f4f2` | Colour and strength in one. |
| | `foamDepth` | `0.3` | Metres of water the band reaches out to. |
| | `foamWobble` | `0.27` | Metres the ripple normals push the band up and down the beach. |
| | `foamLines` | `1` | Roughly how many stripes fit inside the band. |
| | `foamWidth` | `0.02` | Width of one stripe as a fraction of the gap. 1 is no gap. |
| | `foamDrift` | `0.07` | Stripes per second, toward the shore. |
| | `foamEdge` | `0.09` | Metres of solid rim on the contact line. |

## Render order and the opaque canvas

Two conditions make the frame and depth reads valid, and both are already set for you:

- The water is in the **transparent queue** (`material.transparent = true`), so the terrain, props and characters have been drawn when it runs. If the lake ever renders as a black or empty rectangle, the material was sorted opaque and drew first.
- The engine canvas is **opaque**. `Game.vue` builds its `<TresCanvas>` with `createWebGPURenderer`, which does not pass `alpha: true`. A second factory, `createTransparentWebGPURenderer`, exists for canvases whose output composites over the page (portrait bakes, the inventory preview) and is never used for a world scene.

Why the second point matters for water specifically: `alpha: true` configures the canvas context as premultiplied, which gives the **page background** a say in every pixel whose shader writes alpha below 1. The water writes `mask` as alpha, which is 0 over the whole quad outside the lake and ramps through the shoreline. On a transparent canvas the DOM would show through the entire plane except the lake itself. The same applies to any cutout material (`stylizedOutput`'s `alphaTest` path), which is why the opaque renderer is the engine default and not a per-page choice.

::note
`TresCanvas`'s own `:alpha` prop does not reach a custom renderer factory. When you pass `:renderer`, transparency is decided by which factory you pick. The post-processing pages cover the renderer itself.
::

## In the terrain experience

Trimmed from `apps/playground/pages/environment/terrain/experience.vue`. One `createWaterUniforms()` bag is shared with the component; two leches folders write into it.

```ts
const waterNormalMap = whenLoaded(useTexture('/textures/water-normal.webp').state)
const water = createWaterUniforms()

// absorption is the colour eaten, so the surface reads as its complement. level feeds
// both the plane's Y and terrain.waterLevel; they must agree or the damp ring detaches.
const { waterLevel, waterAbsorption, waterStrength, waterDepth, waterEdgeLow, waterEdgeHigh,
  waterRipplesScale, waterRipplesStrength, waterRipplesSpeed, waterRefraction } = useControls('water', {
  level: { value: -1, min: -6, max: 2, step: 0.01, type: 'range' },
  absorption: { value: hex(water.absorption), type: 'color' },
  strength: { value: water.absorbStrength.value, min: 0, max: 3, step: 0.01, type: 'range' },
  depth: { value: water.maxDepth.value, min: 0.5, max: 30, step: 0.1, type: 'range' },
  edgeLow: { value: water.maskLow.value, min: 0, max: 1, step: 0.01, type: 'range' },
  edgeHigh: { value: water.maskHigh.value, min: 0, max: 1, step: 0.01, type: 'range' },
  ripplesScale: { value: water.rippleScale.value, min: 0.1, max: 2, step: 0.01, type: 'range' },
  ripplesStrength: { value: water.rippleStrength.value, min: 0, max: 1, step: 0.01, type: 'range' },
  ripplesSpeed: { value: water.rippleSpeed.value, min: 0, max: 0.1, step: 0.01, type: 'range' },
  refraction: { value: water.refraction.value, min: 0, max: 6, step: 0.05, type: 'range' },
}, { uuid })

bindColor(waterAbsorption!, water.absorption)
bindNumber(waterStrength!, water.absorbStrength)
bindNumber(waterDepth!, water.maxDepth)
bindNumber(waterLevel!, terrain.waterLevel) // the terrain's damp ring follows the plane
// ...

// depth is metres of water, not distance; color doubles as the strength knob
const { foamColor, foamDepth, foamEdge, foamLines, foamWidth, foamDrift, foamWobble } = useControls('foam', {
  color: { value: hex(water.foamColor), type: 'color' },
  depth: { value: water.foamDepth.value, min: 0.05, max: 4, step: 0.01, type: 'range' },
  edge: { value: water.foamEdge.value, min: 0.01, max: 1, step: 0.01, type: 'range' },
  lines: { value: water.foamLines.value, min: 1, max: 12, step: 1, type: 'range' },
  width: { value: water.foamWidth.value, min: 0.02, max: 1, step: 0.01, type: 'range' },
  drift: { value: water.foamDrift.value, min: 0, max: 2, step: 0.01, type: 'range' },
  wobble: { value: water.foamWobble.value, min: 0, max: 1, step: 0.01, type: 'range' },
}, { uuid })
```

```vue
<template>
  <Water
    v-if="control && waterNormalMap"
    :control="control"
    :level="waterLevel"
    :grading="grading"
    :uniforms="water"
    :normal-map="waterNormalMap"
  />
</template>
```

`sunStrength` and `sunSharpness` have no panel knob on this page; they keep their defaults. The `water` folder's `level` slider defaults to `-1`, which overrides both the component default (`-0.35`) and the terrain uniform default (`-1.2`), and the page seeds `terrain.waterLevel.value` from it before the first frame.
