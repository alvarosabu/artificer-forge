`buildTerrainMaterial` returns a `MeshLambertNodeMaterial` whose colour is a splat of up to four surfaces: bare ground, grass, road and rock, plus a wet band along the shore. Grass and road come from the painted [control map](/environment/terrain-heightmap#control-map). Rock comes from slope. Wetness comes from height relative to the water level. Every knob is a uniform, so a debug panel writes into `.value` and nothing is rebuilt.

```ts
import { buildTerrainMaterial, createTerrainUniforms } from '@artificer-forge/engine/runtime'

const uniforms = createTerrainUniforms()
const { material } = buildTerrainMaterial({ control, grading, grassMap, groundMap, roadMap, rockMap, uniforms })
```

Both [`<TerrainQuadtree>`](/environment/terrain-quadtree) and `<TerrainGround>` call it for you. Use it directly only when you build your own ground mesh.

## buildTerrainMaterial

| Option | Type | Default | Purpose |
|--------|------|---------|---------|
| `control` | `ControlMap` | required | r = road weight, g = grass weight, b = water (shore band). |
| `grading` | `GradingContext \| null` | `undefined` | When set, the output goes through `stylizedOutput` and a drop-shadow catcher. See [Grading](/environment/grading). |
| `grassMap` | `Texture` | `undefined` | Tiled albedo for grass. Without it, grass is the `grassDark..grassLight` gradient. |
| `groundMap` | `Texture` | `undefined` | Same for bare ground. |
| `roadMap` | `Texture` | `undefined` | Same for road. |
| `rockMap` | `Texture` | `undefined` | Same for rock. |
| `uniforms` | `TerrainUniforms` | `createTerrainUniforms()` | Pass one in to tune the look live, or to share one bag between two materials. |

Returns `{ material, uniforms }`.

Each map you pass is prepared once, on the CPU: `SRGBColorSpace`, `RepeatWrapping` on both axes (world XZ passes 1 within a metre, so clamping would streak the last row of pixels), `anisotropy = 4`, `needsUpdate`. Texture settings are CPU state and must never be set inside the TSL `Fn`.

## How the colour is built

The layers are applied in a fixed order. Each one is a `mix` over the result of the previous ones.

1. **Bare ground** is the base. It shows wherever nothing else is painted.
2. **Grass** where `control.g` is high: `smoothstep(grassBlendLow, grassBlendHigh, g * edge)`.
3. **Road** on top of grass where `control.r` is high, with the same shape using `roadBlendLow/High`. A path is cut through a field, so painted road wins over painted grass, not the other way round.
4. **Rock** where the surface is steep: `1 - smoothstep(slopeStart, slopeEnd, normalWorld.y)`. Rock is a slope override, not a paint layer, so it goes last. Steep faces are bare stone no matter what the map says is growing there.
5. **Wet ground** near the water line: `h = positionWorld.y - waterLevel`; the band is `(1 - smoothstep(0, dampAbove, h)) * smoothstep(dampBelow, 0, h) * smoothstep(shoreLow, shoreHigh, control.b)`. It darkens whatever material ended up there.

Three noise fields, all in world metres (`mx_noise_float(positionWorld.xz * freq)`), shape the result:

| Node | Built from | Used for |
|------|-----------|----------|
| `grain` | `grainFreq` (about 3 m) | Surface break-up. Road gradient without a map. |
| `patches` | `patchFreq` (about 17 m) | Broad tonal drift, the thing that reads as terrain. |
| `tone` | `mix(grain, patches, 0.75)` | Gradient position for ground, grass and rock without maps; brightness `swing` (0.75..1.25) with maps. Patch-dominated on purpose: equal weight made the surface fizz. |
| `edge` | `(grain - 0.5) * edgeStrength + 1` | Multiplies the painted r and g before the `smoothstep`, so brushed borders crumble instead of ending on a clean curve. Centred on 0.5 so raising the strength widens the wobble without shifting the mask. |

With a map, a surface is `tiledColor(map, tile, warp, warpFreq) * swing * tint`. `tiledColor` fights visible tiling twice: it bends the lookup with a `mx_noise_vec3` warp (`warp` metres at `warpFreq`), then averages two copies of the texture, the second rotated 0.9 rad and scaled 0.61, which never line up with the first. Crossing two grids halves the texture contrast, which is why `swing` is wider than a flat-colour layer would need.

## createTerrainUniforms

37 uniforms, one per knob. Colours are `uniform(Color)`, the rest `uniform(number)`. `tile` values are tiles per metre (0.1 = one tile per 10 m). Frequencies are cycles per metre (1 / freq is the feature size); anything past about 1 is sub-pixel at level-overview distance and reads as static.

Each surface has a dark/light pair **and** a tint. Only one is live: the pair is the gradient used when that surface has no map; the tint multiplies the map when it does.

| Family | Uniform | Default | Purpose |
|--------|---------|---------|---------|
| Ground | `groundDark` | `#7d5f3e` | Gradient low end (no map). |
| | `groundLight` | `#a8834f` | Gradient high end (no map). |
| | `groundTint` | `#ffffff` | Multiplies `groundMap`. |
| | `groundTile` | `0.1` | One tile per 10 m. |
| | `groundWarp` | `3.0` | Metres of lookup warp. |
| Grass | `grassDark` | `#90b070` | |
| | `grassLight` | `#b0c890` | |
| | `grassTint` | `#ffffff` | |
| | `grassTile` | `0.25` | One tile per 4 m. |
| | `grassWarp` | `2.0` | |
| | `grassBlendLow` | `0.25` | `control.g` where grass starts. Also throws away brush overspray below it. |
| | `grassBlendHigh` | `0.6` | `control.g` where grass fully wins. |
| Road | `roadDark` | `#7a7264` | Tight pair on purpose: a wide one reads as salt-and-pepper at grain scale. |
| | `roadLight` | `#98907f` | |
| | `roadTint` | `#ffffff` | |
| | `roadTile` | `0.25` | |
| | `roadWarp` | `2.0` | |
| | `roadBlendLow` | `0.25` | `control.r` band, as for grass. |
| | `roadBlendHigh` | `0.6` | |
| Rock | `rockDark` | `#5b5a5f` | |
| | `rockLight` | `#8d8b90` | |
| | `rockTint` | `#ffffff` | |
| | `rockTile` | `0.1` | |
| | `rockWarp` | `3.0` | |
| | `slopeStart` | `0.62` | `normalWorld.y` where rock starts taking over. |
| | `slopeEnd` | `0.82` | `normalWorld.y` where rock fully wins (flatter than this is never rock). |
| Shore | `wetGround` | `#4a3a28` | Colour the band mixes toward. |
| | `shoreLow` | `0.02` | `control.b` band the darkening ramps across. |
| | `shoreHigh` | `0.15` | |
| | `waterLevel` | `-1.2` | World Y of the water plane. **Must match `<Water level>`.** |
| | `dampAbove` | `0.3` | Metres above the water line that damp sand reaches. |
| | `dampBelow` | `-0.8` | Metres below it before absorption takes over. |
| Noise | `edgeStrength` | `0.5` | Painted-edge wobble. |
| | `grainFreq` | `0.35` | About 3 m. |
| | `patchFreq` | `0.06` | About 17 m. |
| | `rockFreq` | `0.5` | About 2 m. Rock uses its own finer noise, not `tone`: stone reads at a smaller scale than soil. |
| | `warpFreq` | `0.04` | About 25 m. The scale the tile grid is bent at. |

`waterLevel` lives on the terrain, not the water: the damp ring is drawn by the ground. The `<Water>` component positions its plane from its own `level` prop. Feed both from one value or the ring detaches from the surface.

## Grading

With `grading` set, the material stays a `MeshLambertNodeMaterial`. The Lambert lighting result is discarded by the finish; the material is lit only so the shadow catcher runs. `buildTerrainMaterial` wires:

```ts
const dropShadow = createDropShadowCatcher()
material.receivedShadowNode = dropShadow.receivedShadowNode
material.outputNode = stylizedOutput(surfaceColor, grading, {
  hasMidTone: true,
  dropShadowNode: dropShadow.shadowFactor,
})
```

`hasMidTone: true` is deliberate. Hills are the only thing giving this scene form, and two tones alone read flat on a smooth height field. Without `grading`, `colorNode` is the splat and the material is lit by the scene like any Lambert.

## Late textures are ignored

The node graph checks `if (grassMap)` and friends **once**, when `buildTerrainMaterial` runs. A texture that arrives later is not an error and not a warning; that layer just uses the flat dark/light gradient forever. Both `<TerrainGround>` and `<TerrainQuadtree>` build the material in `setup`, so the same applies to their props.

Gate the component on every map:

```vue
<TerrainQuadtree
  v-if="control && heightField && grassMap && groundMap && roadMap && rockMap"
  ...
/>
```

and unwrap `useTexture` results only when `.image` exists (the `whenLoaded` helper on the [height map page](/environment/terrain-heightmap#in-the-terrain-experience)).

## Textures

The playground's terrain textures are WebP files in `apps/playground/public/textures/`: `grass.webp`, `dirt.webp` (ground), `road.webp`, `rock.webp`, plus `water-normal.webp` for the [water](/environment/water). They are projected in **world XZ**, so the tiling ignores whatever UVs the level GLB carries and a texture never stretches on a slope in plan view. Any seamless albedo works; `prepareSurfaceMap` sets the colour space and wrapping for you.

## TerrainGround vs TerrainQuadtree

| | `<TerrainGround>` | `<TerrainQuadtree>` |
|---|---|---|
| Geometry | `geometry` prop, a `BufferGeometry` from the level GLB | Generated from a `HeightField` |
| Vertex shader | none, the mesh's own positions and normals | `sampleHeight` displacement, height-map normals, skirts |
| Picking | three's triangle raycast | `intersectHeightField` |
| Shadows | `receive-shadow` only. Casting would draw the whole ground again into the shadow map (half a million triangles at 512 m) | `receiveShadow` only, same reason |
| Props | `control`, `geometry`, `grading`, `grassMap`, `groundMap`, `roadMap`, `rockMap`, `uniforms` | the same minus `geometry`, plus `field`, `segments`, `maxDepth`, `splitFactor`, `skirtDepth`, `wireframe` |
| Emits | `click` | `click` |

`TerrainGround` is the earlier component from the control-map tutorial. Use it when the ground is a mesh you want drawn as authored. The terrain experience uses `TerrainQuadtree`.

::caution
`TerrainGround` does not forward its `groundMap` prop to `buildTerrainMaterial` (`TerrainGround.vue`, the `buildTerrainMaterial` call omits `groundMap`). Bare ground always renders as the flat gradient there until that is fixed.
::

## In the terrain experience

Trimmed from `apps/playground/pages/environment/terrain/experience.vue`. One uniform bag is created up front and shared with the component; the leches folders write into it. Defaults are read **from** the uniforms so the panel cannot drift from the material.

```ts
const grassMap = whenLoaded(useTexture('/textures/grass.webp').state)
const groundMap = whenLoaded(useTexture('/textures/dirt.webp').state)
const roadMap = whenLoaded(useTexture('/textures/road.webp').state)
const rockMap = whenLoaded(useTexture('/textures/rock.webp').state)

// The material is built once (its graph bakes in which maps exist), so every knob
// below must be a uniform.
const terrain = createTerrainUniforms()

function bindColor(source: Ref<string>, target: { value: Color }) {
  watch(source, hex => target.value.set(hex))
}
function bindNumber(source: Ref<number>, target: { value: number }) {
  watch(source, (v) => { target.value = v })
}
function hex(u: { value: Color }) {
  return `#${u.value.getHexString()}`
}

// dark/light only apply without a map; this page loads all four, so tint is the live knob
const { groundDark, groundLight, groundTint, groundTile, groundWarp } = useControls('ground', {
  dark: { value: hex(terrain.groundDark), type: 'color' },
  light: { value: hex(terrain.groundLight), type: 'color' },
  tint: { value: hex(terrain.groundTint), type: 'color' },
  tile: { value: terrain.groundTile.value, min: 0.01, max: 1, step: 0.01, type: 'range' },
  warp: { value: terrain.groundWarp.value, min: 0, max: 10, step: 0.1, type: 'range' },
}, { uuid })
bindColor(groundDark!, terrain.groundDark)
bindNumber(groundTile!, terrain.groundTile)
// ... same shape for 'grass', 'road', 'rock'

// low/high is the ramp band. grass/road read the control map, rock reads normal.y
const { blendGrassLow, blendGrassHigh, blendRockLow, blendRockHigh, blendEdge } = useControls('blend', {
  grassLow: { value: terrain.grassBlendLow.value, min: 0, max: 1, step: 0.01, type: 'range' },
  grassHigh: { value: terrain.grassBlendHigh.value, min: 0, max: 1, step: 0.01, type: 'range' },
  rockLow: { value: terrain.slopeStart.value, min: 0, max: 1, step: 0.01, type: 'range' },
  rockHigh: { value: terrain.slopeEnd.value, min: 0, max: 1, step: 0.01, type: 'range' },
  edge: { value: terrain.edgeStrength.value, min: 0, max: 2, step: 0.05, type: 'range' },
}, { uuid })

// Damp ring on the terrain, not the water plane
const { shoreColor, shoreLow, shoreHigh, shoreAbove, shoreBelow } = useControls('shore', { /* ... */ }, { uuid })

// frequencies are cycles per metre: 1 / value is the feature size in metres
const { noiseGrain, noisePatch, noiseRock, noiseWarp } = useControls('noise', { /* ... */ }, { uuid })

// the water slider drives both the plane's Y and terrain.waterLevel
bindNumber(waterLevel!, terrain.waterLevel)
terrain.waterLevel.value = toValue(waterLevel!)
```

The seven material folders in the panel are `ground`, `grass`, `road`, `rock`, `blend`, `shore` and `noise`. Folder names are single words because leches builds the destructured keys as `${folder}${Capitalize(control)}`.
