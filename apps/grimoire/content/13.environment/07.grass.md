`<Grass>` draws one blade per lattice cell as a single instanced mesh. `<GrassTufts>` draws coarser fans of blades on the same placement math. Both extend `WindSettings`, take the [grading](/environment/grading) and [trample](/environment/trample) contracts, and can follow a [scatter focus](/environment/scatter) so a fixed blade budget stays around the party leader.

```ts
import { Grass, createGrass, createGrassGeometry, buildGrassMaterial } from '@artificer-forge/engine/runtime'
import { GrassTufts, createGrassTufts, createGrassTuftsGeometry, buildGrassTuftsMaterial } from '@artificer-forge/engine/runtime'
import type { GrassOptions, GrassTuftsOptions, BladeDetail } from '@artificer-forge/engine/runtime'
```

## Basic usage

A flat lawn around the origin, from `apps/playground/pages/environment/day-cycle/experience.vue`:

```vue
<script setup lang="ts">
import { SRGBColorSpace } from 'three'
import { Grass } from '@artificer-forge/engine/runtime'

const { state: grassDiffuseMap } = useTexture('/textures/grass/splat.jpg')
watch(grassDiffuseMap, (tex) => {
  if (tex) tex.colorSpace = SRGBColorSpace
}, { immediate: true })
</script>

<template>
  <!-- diffuseMap presence is decided at material creation, so wait for the texture -->
  <Grass
    v-if="grassDiffuseMap"
    :subdivisions="200"
    :size="30"
    :diffuse-map="grassDiffuseMap"
    :wind-angle="environment.windAngle"
    :wind-strength="environment.windStrength"
    :trample="trampleMap"
    :grading="grading"
  />
</template>
```

`subdivisions: 200` over `size: 30` is 40 000 blades at 44 per m². The splat texture lives in `packages/assets/files/textures/grass/splat.jpg`.

## `<Grass>` props

| Prop | Type | Default | Purpose |
|------|------|---------|---------|
| `subdivisions` | `number` | `200` | Lattice side. Instances = `subdivisions²`. Baked at creation |
| `size` | `number` | `30` | World extent in metres, centred on the origin (or the focus) |
| `colorA` | `TresColor` | `'#b4b536'` | Base colour, mixed with `colorB` by a baked noise (live) |
| `colorB` | `TresColor` | `'#d8cf3b'` | (live) |
| `diffuseMap` | `Texture \| null` | `undefined` | Replaces the two-colour mix with a texture sampled at the blade's world XZ. Swap is live; adding or removing needs a remount |
| `diffuseMapSize` | `number` | `size` | World extent the map spans. On a following field set it to the LEVEL size, not the window |
| `trample` | `TrampleMap \| null` | `undefined` | Flatten, damp wind, and push away from the interactor |
| `grading` | `GradingContext \| null` | `undefined` | Stylized finish; decided at creation |
| `heightField` | `HeightField \| null` | `null` | Lift each blade to the terrain height at its anchor |
| `control` | `ControlMap \| null` | `null` | Placement mask from the control map's green channel |
| `maskLow` | `number` | `0.25` | `control.g` band start: first blades appear |
| `maskHigh` | `number` | `0.6` | Band end: full density. Changing either re-sorts the bake (slider, not per frame) |
| `focus` | `ScatterFocus \| null` | `null` | Turns the field into a `size × size` window that follows the focus |
| `bladeDetail` | `'curved' \| 'flat'` | `'curved'` | Template. The only lever that cuts triangles without changing density |
| `innerSize` | `number` | `undefined` | Carve a hole of this window size in the middle, faded over the same band a field of that size fades out. Used by the far ring |
| `bladeWidth` | `number` | `0.1` | Half-width; the template spans x = ±1 (live) |
| `bladeHeight` | `number` | `0.6` | (live) |
| `bladeHeightRandomness` | `number` | `0.6` | `mix(1, random, randomness)` (live) |
| `shadowIntensity` | `number` | `0.5` | Root darkening. Not a cast shadow: it is AO from base to tip (live) |
| `windAngle` / `windStrength` / `windTimeFrequency` | | see [Wind](/environment/wind) | |

The mesh is `receive-shadow` and `:frustum-culled="!props.focus"`: a following field never leaves the screen, and its origin-centred bounds would cull it by mistake.

## How a blade is built

### Templates

```ts
// curved: 5 verts, 3 tris, bends along its length
positions:  [-1,0,0,  1,0,0,  -0.5,0.7,0,  0.5,0.7,0,  0,1,0]
windWeight: [0, 0, 0.7, 0.7, 1]

// flat: 3 verts, 1 tri, hinges at the base
positions:  [-1,0,0,  1,0,0,  0,1,0]
windWeight: [0, 0, 1]
```

At 10+ blades per m² a blade is about one pixel wide, so `flat` is the free choice there.

### Geometry (`createGrassGeometry`)

Per instance: a jittered lattice `anchor` (vec2), `random`, `yaw`, `heightNoise` in `[0.5, 1.5]` and `colorNoise` in `[0, 1]` from `ImprovedNoise`. The bake (`createScatterBake`) sorts instances by the control mask and the geometry draws only the live prefix: `instanceCount = bake.countFor(MASK_EPSILON)`. Grass is a mask-only species (no density noise), so its coverage IS the mask. The bounding sphere is the half-diagonal plus a 2 m sway margin.

### Vertex shader (`buildGrassMaterial`)

1. `worldXZ = followAnchor(focus, anchor, size)` when following, else `anchor`.
2. `visible = control.g.smoothstep(maskLow, maskHigh)` times `followFade` times `followFadeIn(innerSize)`.
3. Below `MASK_EPSILON` the blade is punted to `PUNT_Y` (10 000) and skips everything else. This matters on a following field, where the CPU bake cannot cull.
4. `height = bladeHeight * mix(1, random, randomness) * heightNoise²`, times `1 - 0.75 * trample`, times the fade.
5. Local shape: `x * bladeWidth * visible`, `y * height`, rotated by `yaw`. Then `+ sampleHeight(heightField, worldXZ)`.
6. Wind: `windOffset(worldXZ) * height * 2`, damped by `1 - trample`, applied `* windWeight`. A droop `|w|² / 2h` (clamped to `0.35 h`) drops the tip so the blade bends instead of stretching.
7. Trample interactor: push away from `trample.uniforms.interactor` with `push²` falloff inside `interactorRadius`.

### Colour

One flat colour per blade (a varying evaluated in the vertex stage): the diffuse map at `bladeXZ / diffuseMapSize + 0.5`, or `mix(colorA, colorB, colorNoise)`. Graded: `stylizedOutput(base, grading, { hasCoreShadows: false, aoNode: rootAo, dropShadowNode })`, where `rootAo = 1 - (1 - windWeight) * shadowIntensity`. Bent-blade normals are noisy, so core shadows are off and the root darkening rides the AO so it re-grades with the cycle. Ungraded: `MeshBasicNodeMaterial`, `mix(base, base * 0.35, ao)`. Both are `DoubleSide`.

## Two-ring pattern

A single field cannot be both dense near the camera and wide enough to reach the fog. The terrain experience runs two `<Grass>` on one focus: a near ring of curved blades and a far ring of flat blades with a hole where the near ring sits. `innerSize` on the far ring is set to the near ring's `size`, and `followFadeIn` is the exact complement of `followFade`, so the two weights sum to 1 across the band and the seam is invisible.

Trimmed from `apps/playground/pages/environment/terrain/experience.vue`:

```vue
<script setup lang="ts">
// Radius sets draw distance AND density, because the instance count is fixed. Keep
// the grass fade at or past where the day fog saturates (~70 m) so the ring never shows.
const GRASS_RADIUS = 150
const NEAR_RADIUS = 30
const GRASS_SUBDIVISIONS = 1024

// Solved, not tuned: holds the far ring's blades per m² so the crossfade shows no density step.
const nearSubdivisions = computed(() =>
  Math.max(4, Math.round(GRASS_SUBDIVISIONS * nearRadius.value / grassRadius.value)))

const scatterFocus = createScatterFocus()
</script>

<template>
  <!-- Keyed on the radii: they are baked into the anchors, and innerSize into the far
       ring's node graph. The splat spans the level so its variation does not tile. -->
  <Grass
    v-if="control && heightField && grassDiffuseMap"
    :key="`near-${nearRadius}-${grassRadius}`"
    :subdivisions="nearSubdivisions"
    blade-detail="curved"
    :diffuse-map="grassDiffuseMap"
    :diffuse-map-size="LEVEL_SIZE"
    :size="nearRadius * 2"
    :focus="scatterFocus"
    :blade-width="bladesWidth"
    :grading="grading"
    :height-field="heightField"
    :control="control"
    :trample="trampleMap"
  />
  <Grass
    v-if="control && heightField && grassDiffuseMap"
    :key="`far-${nearRadius}-${grassRadius}`"
    :subdivisions="GRASS_SUBDIVISIONS"
    blade-detail="flat"
    :diffuse-map="grassDiffuseMap"
    :diffuse-map-size="LEVEL_SIZE"
    :size="grassRadius * 2"
    :inner-size="nearRadius * 2"
    :focus="scatterFocus"
    :blade-width="bladesWidth * bladesFarWidth"
    :grading="grading"
    :height-field="heightField"
    :control="control"
    :trample="trampleMap"
  />
</template>
```

`bladesFarWidth` (default `1.3`) only scales the far ring: a flat blade reads thinner than a curved one at the same width. There is no far height knob on purpose; the crossfade would show the step.

## Mask band

`control.g` is the painted grass channel of the level's control map. Blades ramp in between `maskLow` and `maskHigh` with a `smoothstep`, and the same band is what `controlMaskNode` uses for tufts and flowers, so every species agrees where grass ends. It also matches the band the [terrain material](/environment/terrain-material) blends its grass texture with, which is why vegetation stops at the road for free.

## `createGrass(options)`

```ts
const { geometry, material, uniforms, setMaskBand, dispose } = createGrass(options)
```

| Property | Type | Purpose |
|----------|------|---------|
| `geometry` | `InstancedBufferGeometry` | `instanceCount` already cut to the live prefix |
| `material` | `MeshLambertNodeMaterial \| MeshBasicNodeMaterial` | Graded or standalone |
| `uniforms.bladeWidth` / `bladeHeight` / `bladeHeightRandomness` / `shadowIntensity` | `UniformNode<float>` | Per field, so two rings can differ |
| `uniforms.colorA` / `colorB` | `UniformNode<Color>` | |
| `uniforms.diffuseMap` | `TextureNode \| null` | Set `.value` to swap the texture without a rebuild |
| `uniforms.wind` | `WindUniforms` | Advance with `advanceWindTime` |
| `uniforms.grading` | `GradingContext \| null \| undefined` | The context it was built with |
| `setMaskBand(low, high)` | `(low: number, high: number) => void` | Updates the uniforms and re-sorts the bake when it exists |
| `dispose()` | | |

`createGrassGeometry(options)` returns `{ geometry, bake, rebake }` and `buildGrassMaterial(...)` returns `{ material, diffuseMapNode }` if you need the parts.

## `<GrassTufts>`

Tufts are fans of 18 blades that lean outward as `t²`, so the silhouette arcs instead of spiking. A tuft template is about 160 vertices, so the grid stays coarse and density does the work.

```vue
<GrassTufts
  v-if="control && heightField"
  :subdivisions="40"
  :size="flowerRadius * 2"
  :focus="scatterFocus"
  :grading="grading"
  :height-field="heightField"
  :control="control"
  :trample="trampleMap"
  :density="0.35"
  :height="2.2"
  :spread="0.45"
  color-a="#2f5d2a"
  color-b="#7fae3c"
  :wind-angle="environment.windAngle"
  :wind-strength="environment.windStrength"
/>
```

| Prop | Type | Default | Purpose |
|------|------|---------|---------|
| `subdivisions` | `number` | `20` | Keep coarse; instances = `subdivisions²` |
| `size` | `number` | `30` | |
| `blades` | `number` | `18` | Blades per fan. Read at creation |
| `segments` | `number` | `4` | Segments per blade. Read at creation |
| `height` | `number` | `2.2` | (live) |
| `spread` | `number` | `0.45` | Scales fan radius and blade width together (live) |
| `density` | `number` | `0.35` | 1 keeps every tuft, 0 keeps none. Live: moves the draw count (baked) or the threshold (shader) |
| `densityMap` | `Texture \| null` | `undefined` | Extra placement mask, one species per channel |
| `densityMapSize` | `number` | `size` | World extent of that map |
| `densityChannel` | `'r' \| 'g' \| 'b' \| 'a'` | `'r'` | |
| `control` / `maskLow` / `maskHigh` | | `null` / `0.25` / `0.6` | Same band as grass |
| `heightField` | `HeightField \| null` | `null` | One height per tuft, sampled at the anchor, so the fan keeps its shape on a slope |
| `colorA` | `TresColor` | `'#2f5d2a'` | Blade base |
| `colorB` | `TresColor` | `'#7fae3c'` | Blade tip. The ramp is skewed per instance so neighbours do not share one palette |
| `seed` | `string` | `'tufts'` | |
| `trample` / `grading` / `focus` | | | Same contracts as grass. Tufts are stiffer: height `* (1 - 0.55 * trample)` |
| `windAngle` / `windStrength` | | | |

Differences from `<Grass>`:

- Per-instance values are packed into one `instanceData` vec4 (`random`, `yaw`, `heightNoise`, `colorNoise`) because WebGPU allows 8 vertex buffers per pipeline.
- Placement is noise AND mask: `coverageNode` mixes a fine density noise (frequency `0.16`, so tufts want scattered spots, not fields) with the mask and the optional density map. On a static field the bake resolves the whole test on the CPU and the shader skips it (`baked = bake.masked`). On a following field only the noise is baked and the shader still tests the mask.
- `createGrassTufts` returns `setDensity(density)` in addition to `setMaskBand`.

## Gotchas

::warning
- **`diffuseMap` and `densityMap` presence is fixed at creation.** The node graph bakes in whether a texture exists. Gate the component with `v-if` on the loaded texture, then swap freely.
- **`useTexture` hands you a pixel-less `Texture` first.** A WebGPU material given one throws in bind-group init every frame and leaves a blank page. Check `texture.image` before passing it (the terrain experience's `whenLoaded` helper).
- **The instance count is fixed.** With a focus, `size` sets the draw distance AND the density. A wider window is a thinner lawn unless you raise `subdivisions`.
- **`subdivisions`, `size`, `focus`, `innerSize`, `bladeDetail` and `blades`/`segments` need a remount.** They are baked into the anchors or the node graph. Key the component on them.
- **`maskLow`/`maskHigh` re-sort and re-upload the instance buffer.** Fine for a slider, not for per-frame animation.
- **A following field cannot be pre-sorted.** The mask moves with the window, so every blade is drawn and the vertex early-out does the culling. Expect a following field to cost its full `subdivisions²` in vertex work.
- **`shadowIntensity` is root AO, not a cast shadow.** The name is historical.
::
