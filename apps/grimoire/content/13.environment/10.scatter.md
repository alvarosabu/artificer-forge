Grass, tufts and flowers all place instances on a fixed-size lattice and decide per instance whether it lives. Two helpers in `runtime/components/scatter/` do that work so the three species agree with each other and with the terrain material: `focus.ts` moves the lattice with the party, `density.ts` computes coverage on the GPU and, when it can, on the CPU too.

```ts
import {
  createScatterFocus, followAnchor, followFade, followFadeIn,
  coverageNode, controlMaskNode, channelNode, createDensityMapNode,
  createScatterBake, countAbove, MASK_EPSILON, PUNT_Y,
} from '@artificer-forge/engine/runtime'
import type { ScatterFocus, ScatterFocusSettings, DensityChannel, CoverageOptions, ScatterBake, ScatterBakeInput } from '@artificer-forge/engine/runtime'
```

## Focus: a lattice that follows the player

The grids have a fixed instance count. A fixed blade budget spread over a whole level is haze; wrapped around the party leader it is a lawn. The looping-grid trick comes from Bruno Simon's Folio 2025.

### `createScatterFocus(settings)`

```ts
function createScatterFocus(settings?: { x?: number, z?: number, fadeStart?: number }): ScatterFocus
```

| Member | Type | Default | Purpose |
|--------|------|---------|---------|
| `center` | `UniformNode<vec2>` | `(0, 0)` | World XZ the windows wrap around |
| `fadeStart` | `UniformNode<float>` | `0.85` | Fraction of the half-window where the edge fade starts. A uniform, so it moves without a node-graph rebuild |
| `set(x, z)` | | | Move the centre |
| `setFadeStart(value)` | | | `1` = hard cut |

One focus per scene. The terrain experience updates it at loop priority 10, after the character controller has moved:

```ts
const scatterFocus = createScatterFocus()

onBeforeRender(() => {
  const leaderPos = playerId.value ? getCharacterRef(playerId.value)?.getPosition() : null
  if (leaderPos) {
    trampleMap.setInteractor(leaderPos.x, leaderPos.z)
    scatterFocus.set(leaderPos.x, leaderPos.z)
  }
}, 10)
```

### TSL helpers

```ts
followAnchor(focus, anchor, size)    // Node<'vec2'>: anchor wrapped into the size × size window around focus.center
followFade(focus, worldXZ, size)     // Node<'float'>: 1 inside, 0 at the window edge
followFadeIn(focus, worldXZ, size)   // Node<'float'>: 1 - followFade
```

- `followAnchor` returns `anchor + k * size` for a whole `k`, so an instance never slides. It teleports one full width ahead when it falls behind the far edge. Every baked per-instance value (random, yaw, noise) therefore repeats with period `size`.
- `followFade` uses Chebyshev distance, not radial. The window is a square, so fading to its own edge wastes no corner instances. It is `smoothstep(fadeStart, 1)` on `max(|dx|, |dz|) / (size / 2)`, inverted.
- `followFadeIn` is the exact complement, so a far ring fading in over the band a near ring fades out sums to 1: no seam. This is the [two-ring grass](/environment/grass#two-ring-pattern) pattern.

Components multiply the fade into blade height and local scale, so instances shrink into the ground at the wrap boundary instead of popping.

## Coverage: does this instance live?

### `controlMaskNode(control, worldXZ, low?, high?)`

`texture(control).g.smoothstep(low, high)`. The green channel of the [control map](/environment/terrain-material) is the painted grass mask. This is the SAME band grass blades test, so blades, tufts and flowers agree on where grass ends, and vegetation stops at the road for free.

### `createDensityMapNode(map, worldXZ, size)`

Samples an optional per-species density texture at the instance's WORLD position, `worldXZ / size + 0.5`. `size` is the map's level extent, not the field's. Returns `null` when there is no map. `channelNode(node, channel)` picks `r`, `g`, `b` or `a`.

### `coverageNode(options)`

```ts
coverage = mix(densityNoise, random, jitter)      // jitter default 0.25, so patch edges are not a clean contour
         * controlMaskNode(...)                    // when control is set
         * channelNode(densityMapNode, channel)    // when a density map is set
```

| Option | Type | Purpose |
|--------|------|---------|
| `anchor` | `Node<'vec2'>` | World XZ to sample masks at |
| `control` / `maskLow` / `maskHigh` | | Mask band |
| `densityMapNode` / `channel` | | Optional density texture, default channel `'r'` |
| `densityNoise` | `Node<'float'>` | Baked per-instance patch noise |
| `random` | `Node<'float'>` | Baked white noise mixed in by `jitter` |
| `jitter` | `number` | Default `0.25` |

Flowers and tufts then test `step(threshold, coverage)` with `threshold = 1 - density`. Grass has no noise term: its coverage IS the mask and it tests against `MASK_EPSILON`.

### Constants

| Name | Value | Purpose |
|------|-------|---------|
| `MASK_EPSILON` | `0.01` | Grass punts blades under this, so cutting them on the CPU changes no pixels |
| `PUNT_Y` | `10000` | Rejected instances park here, past the far plane, so they clip whole. It is the DEFAULT position in every scatter vertex program: a dead instance skips height, trample and wind |

## Bake: do the test once on the CPU

`createScatterBake` is the CPU twin of `coverageNode`. It computes the same coverage per instance, sorts the instance buffers DESCENDING by it, and hands back a function that says how many leading instances pass a threshold. The component sets `geometry.instanceCount` to that prefix and the GPU never sees the dead ones.

```ts
function createScatterBake(input: ScatterBakeInput): ScatterBake
```

### Input

| Field | Type | Purpose |
|-------|------|---------|
| `count` | `number` | Instances |
| `anchors` | `Float32Array` | Stride 2. Rewritten IN PLACE in sorted order |
| `attributes` | `{ array: Float32Array, stride: number }[]` | Every other per-instance buffer, re-ordered alongside the anchors |
| `noise` | `{ densityNoises, randoms, jitter? } \| null` | Omit for a mask-only species (grass) |
| `control` | `ControlMap \| null` | Read with `readControlPixels` |
| `maskLow` / `maskHigh` | `number` | Band |
| `densityMap` | `Texture \| null` | Its presence DECLINES the bake (see below) |
| `moving` | `boolean` | The field follows a focus, so only the noise term is static |

### Return

| Member | Type | Purpose |
|--------|------|---------|
| `coverage` | `Float32Array \| null` | Descending, in buffer order. `null` means the shader still tests |
| `masked` | `boolean` | `true` when the bake is the WHOLE test and the shader can drop it |
| `countFor(threshold)` | `(t: number) => number` | Leading instances with coverage `>= threshold` |
| `rebake(maskLow, maskHigh)` | `(low, high) => boolean` | Re-sort from the UNSORTED originals for a new band. `false` when there is nothing to rebake |

### When the bake declines

The bake returns `{ coverage: null, masked: false, countFor: () => count, rebake: () => false }` when:

- a `densityMap` is present (its UV mapping and `flipY` are not reproduced on the CPU), or
- there are no control pixels to read AND the field is not `moving` with a noise term.

What each component ends up with:

| Situation | `coverage` | `masked` | Shader |
|-----------|-----------|----------|--------|
| Static field, control map, noise (flowers, tufts) | full | `true` | Skips the test (`baked`) |
| Static field, control map, no noise (grass) | mask | `true` | Punts below `MASK_EPSILON` (already cut) |
| Following field with noise (flowers, tufts + focus) | noise only | `false` | Still tests the mask. The prefix is only a superset: a mask `<= 1` cannot rescue noise under the threshold |
| Following grass (no noise) | `null` | `false` | Draws every blade, punts in the vertex stage |
| Any field with a `densityMap` | `null` | `false` | Full test in the shader; `density` moves a threshold, not a count |

### The twin contract

The two implementations MUST produce the same number, or the CPU cuts instances the GPU would draw (or the reverse). `density.test.ts` pins the contract:

- `smoothstep` matches TSL's (`t² (3 - 2t)`, and `x < low ? 0 : 1` when `high === low`).
- The formula is `(patch + (random - patch) * jitter) * mask`, the same `mix(densityNoise, random, jitter)`.
- `countAbove` uses `>=`, matching `step(threshold, coverage)` which passes on equal, and rounds the threshold with `Math.fround` first because `Math.fround(0.9)` is a hair below `0.9` and exact ties would be lost.
- `sampleControlChannel` reads texel centres exactly, interpolates between them, clamps at the edge, follows the map origin, and reads row 0 at `v = 0` because the control map does not flip Y.

If you change `coverageNode`, change `run()` in `createScatterBake` and the test in the same commit.

## Gotchas

::warning
- **Anchors are reordered in place.** After `createScatterBake` the `anchors` array is sorted. Build your `InstancedBufferAttribute` from it AFTER the bake, and flag `needsUpdate` after a `rebake`.
- **Only one `densityNoise` buffer when it is needed.** Components add the `densityNoise` attribute only when `!bake.masked`, to keep a vertex buffer free (WebGPU allows 8). Do not read it in a shader path that is `baked`.
- **`rebake` is a slider operation.** It re-sorts and re-uploads every instance buffer. Never call it per frame.
- **`size` for the density map is the level's extent.** With a focus the window moves; the map does not.
- **A moving field always costs its full instance count in vertex work.** The bake cannot cull for it. Keep `subdivisions` honest.
::
