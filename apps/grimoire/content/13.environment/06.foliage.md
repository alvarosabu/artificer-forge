title: Foliage
description: The Foliage component and createFoliage factory: GPU-instanced billboard leaf clusters with per-frame camera facing, wind flutter, trample squash and the grading finish.
---

`<Foliage>` renders bushes and canopies as clusters of leaf quads distributed on a sphere. Every reference `Object3D` becomes one cluster instance; one merged cluster geometry times N instances is a single draw call. Each quad is turned to face the camera in the vertex shader, so the blob keeps its full leaf silhouette from any orbit angle.

```ts
import { Foliage, createFoliage, applyFoliageTexture } from '@artificer-forge/engine/runtime'
import type { FoliageOptions } from '@artificer-forge/engine/runtime'
```

## Basic usage

Trimmed from `apps/playground/pages/environment/day-cycle/experience.vue`:

```vue
<script setup lang="ts">
import { Object3D } from 'three'
import { createGradingContext, createTrampleMap, Foliage, useEnvironmentStore } from '@artificer-forge/engine/runtime'

const references = [
  { position: [2, 0, -3] as [number, number, number], scale: 1.0 },
  { position: [-4, 0, 1] as [number, number, number], scale: 0.8 },
  { position: [5, 0, 4] as [number, number, number], scale: 1.2 },
].map(({ position, scale }) => {
  const obj = new Object3D()
  obj.position.set(...position)
  obj.scale.setScalar(scale)
  obj.updateMatrixWorld()
  return obj
})

const { state: foliageTexture } = useTexture('/textures/foliage/foliageSDF.png')
const environment = useEnvironmentStore()
const grading = createGradingContext({ sceneNear: 12, sceneFar: 45 })
const trampleMap = createTrampleMap({ size: 30, resolution: 256 })
</script>

<template>
  <Foliage
    :references="references"
    :foliage-texture="foliageTexture"
    color-a="#b4b536"
    color-b="#d8cf3b"
    :amount="80"
    :size="0.8"
    :wind-angle="environment.windAngle"
    :wind-strength="environment.windStrength"
    :trample="trampleMap"
    :grading="grading"
  />
</template>
```

Each reference's world position places the cluster and its largest axis scale sizes it.

::warning
Call `updateMatrixWorld()` on each reference before passing it. The factory reads `matrixWorld`, not `position` and `scale`.
::

## Props

`Foliage.vue` takes `FoliageOptions` directly:

| Prop | Type | Default | Purpose |
|------|------|---------|---------|
| `references` | `Object3D[]` | `[]` | One cluster per reference. Baked into the instance buffer at setup |
| `amount` | `number` | `80` | Leaf quads per cluster. Baked into the geometry at setup |
| `size` | `number` | `0.8` | Quad edge in metres at cluster scale 1 |
| `colorA` | `TresColor` | `'#b4b536'` | Shadow-side colour (live) |
| `colorB` | `TresColor` | `'#d8cf3b'` | Light-side colour (live) |
| `seed` | `string` | `'foliage'` | Deterministic RNG seed for quad layout and instance yaw |
| `foliageTexture` | `Texture \| null` | `undefined` | Red channel is the leaf cutout. Can arrive after mount |
| `lightingDirection` | `Vector3` | `(1, 1, 0)` normalized | Colour ramp direction on the UNGRADED path only. Ignored when `grading` is set |
| `trample` | `TrampleMap \| null` | `undefined` | Clusters squash toward y = 0 where the map is marked |
| `grading` | `GradingContext \| null` | `undefined` | Switches to the stylized finish. Decided at creation |
| `windAngle` | `number` | `DEFAULT_WIND_ANGLE` | See [Wind](/environment/wind) (live) |
| `windStrength` | `number` | `DEFAULT_WIND_STRENGTH` | (live) |
| `windTimeFrequency` | `number` | `0.5` | Read at creation |

The component renders `<TresInstancedMesh :args="[geometry, material, count]" cast-shadow receive-shadow :frustum-culled="false" />` and advances the wind clock in `onBeforeRender`.

## Textures

The leaf alpha textures ship in `packages/assets/files/textures/foliage/`:

| File | Use |
|------|-----|
| `foliage.png` | Plain leaf alpha |
| `foliageSDF.png` | SDF version, cleaner cutout edge at the 0.3 test. The playground uses this one |
| `foliageSDF.ktx` | Compressed SDF |

The `@artificer-forge/assets` Nuxt module serves the folder, so the URL is `/textures/foliage/foliageSDF.png`. `useTexture` resolves after mount; the component's `foliageTexture` watcher calls `setTexture` when it lands.

## How it works

### Cluster geometry (`buildClusterGeometry`)

For each of `amount` quads:

1. A `PlaneGeometry(size, size)` is spun in-plane by a random Z angle. It is NOT tilted toward the sphere surface: tilted quads near the silhouette turn edge-on and the blob reads as shards.
2. The spun corner offsets are saved into a `corner` (vec2) attribute.
3. The quad is placed on the sphere at radius `1 - rng()³` (biased toward the shell), then all four vertices are collapsed onto that anchor. `position` now carries the leaf ANCHOR, and the shader rebuilds the quad from `corner`.
4. Normals are the vertex position lerped 85% toward the outward direction, intentionally not normalized, for softer shading. They are measured at the real vertex positions before the collapse.
5. An `ao` attribute bakes depth into the cluster (0 core, 1 surface), ramped 3× because the radius distribution piles quads near the surface.

Everything is merged into one `BufferGeometry`.

### Instances (`buildInstanceMatrices`)

Per reference: world position, uniform scale = `matrixWorld.getMaxScaleOnAxis()`, and a random yaw. No billboard rotation lives in the matrix. The yaw only varies the baked fake-spherical normals between bushes, so they do not all catch the light on the same side. A second `instanceScale` attribute carries the scale, because the quad corners are expanded AFTER the instance transform and would otherwise all be 1.0-sized.

### Vertex shader (`positionNode`)

```
anchor = positionLocal (instanced)
if trample: anchor.y *= 1 - 0.6 * trample(anchor.xz)
corner  = rotateUV(corner, flutter, 0) * instanceScale     // flutter = |windOffset(anchor.xz)| * 2.2
return anchor + cameraRight * corner.x + cameraUp * corner.y
```

`cameraWorldMatrix` follows whichever camera is rendering, so in the shadow pass the quads face the LIGHT. The wind flutter spins the quad, not the UV: a rotated UV swings outside `[0, 1]` and the clamp-to-edge border slices chunks off leaves near the corners.

### Material

Two paths, chosen once by `grading`:

| | `grading` set | `grading` null |
|---|---|---|
| Class | `MeshLambertNodeMaterial` | `MeshStandardNodeMaterial` |
| Colour | `stylizedOutput(mix(colorA, colorB, normalWorld · lightDirection), ...)` with `aoNode` = baked `ao`, `dropShadowNode`, `alphaNode` = texture red, `alphaTest: 0.3` | `colorNode` = `mix(colorA, colorB, normalWorld · lightingDir)` |
| Cutout | Discard inside the finish, after fog | `opacityNode` = texture red, `material.alphaTest = 0.3` |
| Shadow receive | `createDropShadowCatcher` on `receivedShadowNode` | `receivedShadowPositionNode = positionLocal + lightingDir` |

Common to both: `side` stays `FrontSide`, `shadowSide = FrontSide`, `depthWrite: true`, `transparent: false`. `castShadowNode` discards texels with red `< 0.5` and returns `vec4(0, 1, 1, 1)` (the WebGPU shadow-pass convention, not a colour).

Why `FrontSide`: the quads already face the camera, so a back face only appears on a quad turned away, and rendering those double-sided piles unlit leaves into the blob. Why `shadowSide = FrontSide`: three flips a `FrontSide` material to `BackSide` for the shadow map. A billboard has no back shell, so on `BackSide` every quad is culled and the canopy casts nothing, silently. `foliage.test.ts` ("keeps the front face in the shadow pass") guards this.

### Seeded RNG

All randomization uses `mulberry32` seeded from a string hash. The same `seed` gives identical geometry and yaws. The sequence is shared: geometry consumes 4 values per quad, then instances consume 1 per reference. Changing `amount` therefore also changes the instance yaws.

## Factory

```ts
const { geometry, material, uniforms, count, setTexture, dispose } = createFoliage({
  references, amount: 80, size: 0.8,
  colorA: '#b4b536', colorB: '#d8cf3b',
  seed: 'my-forest', foliageTexture, trample, grading,
  windAngle, windStrength,
})
```

| Property | Type | Purpose |
|----------|------|---------|
| `geometry` | `BufferGeometry` | Merged cluster with `position`, `normal`, `uv`, `corner`, `ao` |
| `material` | `MeshLambertNodeMaterial \| MeshStandardNodeMaterial` | Graded or standalone |
| `uniforms.colorA` | `UniformNode<Color>` | Shadow-side colour |
| `uniforms.colorB` | `UniformNode<Color>` | Light-side colour |
| `uniforms.lightingDir` | `UniformNode<Vector3>` | Ungraded ramp direction |
| `uniforms.wind` | `WindUniforms` | `direction`, `strength`, `localTime`, ... Advance with `advanceWindTime` |
| `count` | `number` | `references.length` |
| `setTexture(tex)` | `(tex: Texture) => void` | Rewires the alpha for whichever path is active, and rebuilds the graded `outputNode` |
| `dispose()` | `() => void` | Disposes geometry and material |

`applyFoliageTexture(material, tex, wind, grading?)` is also exported: it sets `castShadowNode` and, on the ungraded path, `opacityNode`.

## Gotchas

::warning
- **`references`, `amount` and `seed` are baked at setup.** Changing them after mount does nothing. Remount with a `:key`, which is what `<Trees>` does.
- **`lightingDirection` is ignored with `grading`.** The graded ramp reads `grading.uniforms.lightDirection`. Keep the light and the finish in one place.
- **Do not put the trample map on canopies.** The squash pulls anchors toward y = 0, which is the ground under a bush but several metres below a tree canopy. `<Trees>` omits it on purpose.
- **`uniform()` wants raw values.** The factory passes `new Color(...)`; passing a TSL `color()` node instead gives a zero-size GPU buffer.
- **No `DoubleSide`, no `opacityNode` on the graded path.** Both were true of an older build and both are wrong now. See the material table.
::
