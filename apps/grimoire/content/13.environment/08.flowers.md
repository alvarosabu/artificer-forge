`<Flowers>` renders one species as one instanced draw: a stem strip plus a procedural head, no textures, colours as uniforms so a species can be retinted live. It shares the scatter grid, the coverage bake, the wind, trample and grading contracts with [Grass](/environment/grass) and [GrassTufts](/environment/grass#grasstufts). Three components make a meadow.

```ts
import { Flowers, createFlowers, createFlowersGeometry, buildFlowersMaterial, FLOWER_PRESETS } from '@artificer-forge/engine/runtime'
import type { FlowersOptions, FlowerShape } from '@artificer-forge/engine/runtime'
```

## Usage

Trimmed from `apps/playground/pages/environment/terrain/experience.vue`:

```vue
<script setup lang="ts">
const { puffsDensity, puffsHeight, puffsColor } = useControls('puffs', {
  density: { value: 0.5, min: 0, max: 1, step: 0.01, type: 'range' },
  height: { value: 0.85, min: 0.1, max: 1.5, step: 0.01, type: 'range' },
  color: { value: '#ffffff', type: 'color' },
}, { uuid })
</script>

<template>
  <Flowers
    v-if="control && heightField"
    :key="flowerRadius"
    shape="puff"
    :subdivisions="200"
    :size="flowerRadius * 2"
    :focus="scatterFocus"
    :grading="grading"
    :height-field="heightField"
    :control="control"
    :trample="trampleMap"
    :density="puffsDensity"
    :height="puffsHeight"
    :petal-color="puffsColor"
    :wind-angle="environment.windAngle"
    :wind-strength="environment.windStrength"
  />
  <Flowers shape="poppy" :subdivisions="100" :size="flowerRadius * 2" :focus="scatterFocus" :grading="grading" ... />
  <Flowers shape="daisy" :subdivisions="80" :size="flowerRadius * 2" :focus="scatterFocus" :grading="grading" ... />
</template>
```

The mesh is named `Flowers:${shape}` in the scene graph, `receive-shadow`, and `:frustum-culled="!props.focus"`.

## Shapes

`FlowerShape = 'puff' | 'poppy' | 'daisy'`. Each maps to a `FLOWER_PRESETS` entry that defines the head geometry and the default colours. Two head builders exist:

- **`puff`**: `quads` camera-agnostic quads on a spherical cap (not a full sphere, quads below the equator would poke into the stem), oriented outward with `lookAt`. The quads must overlap to read as a ball; fewer or smaller reads as a spiky star.
- **`petals`**: `quads` petals in a ring at `radius` from the axis, each flat, tilted by `tilt`, plus an optional centre disc when `center > 0`.

| Preset | Head | `quads` | `height` | `headSize` | `petalColor` | `petalColorB` | `stemColor` | `centerColor` |
|--------|------|---------|----------|------------|--------------|---------------|-------------|---------------|
| `puff` | puff | 14 | 0.85 | 0.075 | `#ffffff` | `#eef1e2` | `#8fa04a` | `#ffffff` (no disc) |
| `poppy` | petals | 5 | 0.44 | 0.12 | `#c4202a` | `#dd4433` | `#7f9440` | `#2b1a14` |
| `daisy` | petals | 7 | 0.32 | 0.1 | `#e8c22a` | `#f4dd5a` | `#87a04a` | `#a9760f` |

The presets also carry `petalLength`, `petalWidth`, `radius`, `tilt`, `liftY`, `center`, `centerY` and `stemWidth` (0.012, daisy 0.01). Puff height `0.85` clears the default grass blade tips (`0.6`).

`Flowers.vue` takes `FlowersOptions`:

| `subdivisions` | `number` | `70` | Instances = `subdivisions²`. Use the same scale as Grass |
| `size` | `number` | `30` | Field extent in metres |
| `density` | `number` | `0.55` | 1 keeps everything, 0 keeps nothing (live) |

| `control` | `ControlMap \| null` | `null` | Placement mask from `control.g` |
| `maskLow` | `number` | `0.25` | Band where the species ramps in: low = first flowers |
| `maskHigh` | `number` | `0.6` | high = full |
| `heightField` | `HeightField \| null` | `null` | One height per flower at its anchor, so a stem on a slope stays straight |
| `petalColor` | `TresColor` | preset | (live) |
| `petalColorB` | `TresColor` | preset | Mixed with `petalColor` by the per-instance colour noise (live) |
| `stemColor` | `TresColor` | preset | (live) |
| `centerColor` | `TresColor` | preset | (live) |
| `height` | `number` | preset | Stem height (live) |

| `grading` | `GradingContext \| null` | `undefined` | Decided at creation |
| `focus` | `ScatterFocus \| null` | `null` | Following window |

## How it works

### Template

One template per species: the 5-vertex grass stem strip (`windWeight` `[0, 0, 0.7, 0.7, 1]`) plus the head quads. Each vertex carries a `vertexData` vec3: `x` wind weight (head quads take 1, they sit at the stem tip), `y` part id (`0` stem, `1` petal, `2` centre), `z` openness (stem base is buried in grass, so it reuses the wind weight as AO). No normal attribute: the finish skips core shadows.

### Instances

Same lattice as grass. `instanceData` vec4 packs `random`, `yaw`, `heightNoise`, `colorNoise` (WebGPU's 8 vertex buffer limit). A `densityNoise` per instance uses a coarser frequency than grass patchiness (`0.09`, gain `1.6`) so clumps read as beds with sharp edges. The bake sorts by coverage; `instanceCount = bake.countFor(1 - density)`.

### Vertex shader

1. `worldXZ = followAnchor(...)` when following; `fade = followFade(...)`.
2. Unless baked, `alive = step(threshold, coverageNode({...})) > 0.5`. On a following field the bake only prunes by noise, so mask rejects reach the draw; running height, trample and wind for them was most of the cost of a bed that is mostly road. Dead instances sit at `PUNT_Y`.
3. `stemHeight = height * mix(0.75, random, 0.55) * heightNoise`, trample and fade applied.
4. Stem verts are in blade space (`x * stemWidth`, `y * stemHeight`); head verts are in head-local units above the tip (`* headSize`, `+ stemHeight`). One `step(0.5, part)` switch instead of two draws. Rotated by `yaw`, lifted by `sampleHeight`.
5. Wind `* stemHeight * 1.8 * windWeight` with the droop `|w|² / 2h` clamped to `0.35 h`.
6. Trample interactor push (`push² * 0.5 * windWeight`, drop `0.3 * stemHeight`).

### Colour

`part` is constant across a quad, so a varying picks the palette: `petal = mix(petalColor, petalColorB, colorNoise)`, then stem or petal by `step(0.5, part)`, then centre by `step(1.5, part)`. Graded: `stylizedOutput(base, grading, { hasCoreShadows: false, aoNode, dropShadowNode })` with `ao = 1 - (1 - openness) * 0.45`. Ungraded: `MeshBasicNodeMaterial`, `mix(base, base * 0.35, ao)`. `DoubleSide`.

## `createFlowers(options)`

```ts
const { geometry, material, uniforms, setDensity, setMaskBand, dispose } = createFlowers(options)
```

| Property | Type | Purpose |
|----------|------|---------|
| `geometry` | `InstancedBufferGeometry` | `instanceCount` cut to the passing prefix |
| `material` | `MeshLambertNodeMaterial \| MeshBasicNodeMaterial` | |
| `uniforms.petalColor` / `petalColorB` / `stemColor` / `centerColor` | `UniformNode<Color>` | |
| `uniforms.height` / `headSize` / `stemWidth` / `threshold` / `shadowIntensity` / `maskLow` / `maskHigh` | `UniformNode<float>` | `threshold = 1 - density`; `shadowIntensity` is fixed at `0.45` |
| `uniforms.densityMap` | `TextureNode \| null` | Swap `.value` |
| `uniforms.wind` | `WindUniforms` | |
| `uniforms.grading` | `GradingContext \| null \| undefined` | |
| `setDensity(density)` | `(d: number) => void` | Baked: moves `instanceCount`. Shader path: moves the threshold |
| `setMaskBand(low, high)` | | Re-sorts when a bake exists, then re-applies the density |
| `dispose()` | | |

An unknown `shape` falls back to `FLOWER_PRESETS.puff`.

## Gotchas

::warning
- **One species per component.** Each `<Flowers>` is one draw with one template. Mixing species means multiple components; they all take the same `focus` and `:key`.
- **Scatter grids are per species on purpose.** A flower template is about 60 vertices; keep `subdivisions` proportional to how many you can afford (the playground uses 200 puffs, 100 poppies, 80 daisies at a 60 m radius).
- **A `densityMap` declines the CPU bake.** Its UV mapping and `flipY` are not reproduced on the CPU, so the shader does the full coverage test and `density` becomes a threshold instead of a draw count.
- **`shape`, `subdivisions`, `size`, `focus` and `seed` are baked.** Remount to change them.
- **Colours snap to the preset unless you pass them.** `petalColor` alone leaves `petalColorB` at the preset value, so a red poppy keeps its `#dd4433` highlight. Pass both for a full retint.
::
