# Context Map

Each package is its own bounded context with its own glossary. Read the glossary of the package you touch before naming things; read the Engine's whenever you are unsure, since every other context borrows its terms.

## Contexts

- [Engine](./packages/engine/CONTEXT.md) — the game runtime: entities, party, combat, status effects, surfaces, inventory, dialog runtime, portraits, terrain and grading
- [VFX](./packages/vfx/CONTEXT.md) — combat markers, damage numbers, surface and character materials, particles
- [Post-processing](./packages/post-processing/CONTEXT.md) — the full-frame pipeline: bloom, depth of field, tilt-shift, godrays, outlines, antialiasing
- [Dialog Editor](./packages/dialog-editor/CONTEXT.md) — the visual authoring tool for dialog trees
- [Assets](./packages/assets/CONTEXT.md) — shared models, textures, animations and the part manifest for modular characters

Not yet mapped: `packages/utils` (one helper), `packages/level-studio` (no source on `main`), and the apps, whose vocabulary is the Engine's.

## Relationships

- **Engine → VFX**: the Engine mounts VFX components and materials and packs the field texture that VFX materials sample; VFX never reads a store
- **Engine → Post-processing**: `<Game>` mounts the effect composer and installs the focus target, godrays light and outline group providers
- **Assets → Engine**: the part manifest is generated by Assets and registered into the Engine once at startup; the Engine turns an appearance into a modular assembly from it
- **Dialog Editor ↔ Engine**: both read and write the same dialog YAML; conversation terms are shared, canvas terms are editor-only
- **Apps → Engine**: apps inject a content source and policy (presets, day cycle); the Engine supplies mechanism

## Reserved words

When a word has a home context, other contexts use the qualified form.

- **node** → Dialog Editor (a dialog node). Elsewhere say "graph node", "quadtree node" or "TSL node"
- **scene** → Engine (a YAML level). Three's object is "Three scene"
- **slot** → Engine (an equipment slot). Say "modular slot", "action slot", "slot folder"
- **effect** → never bare. Say "status effect", "dialog effect" or "pass"
- **focus** → Post-processing (the focus target). The Engine says "scatter focus"
- **rig** → Assets (a bare skeleton). Say "animation pack" for rig-sized clip sets and "portrait preset" for the bake camera
- **kind** → Engine (a surface kind); VFX borrows it for liquids
- **target** → Engine (a combat target); Post-processing says "focus target"
- **grading** → Engine (stylized lighting). Post-processing has no grading
- **field texture** → VFX name for what the Engine packs; the docs' "field map" is retired
